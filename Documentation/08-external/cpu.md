# Intel Xeon E5-2687W v4 — Процессор

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Модель | Intel Xeon E5-2687W v4 |
| Семейство | Intel Xeon E5 v4 (Broadwell-EP) |
| Сокет | LGA 2011-3 |
| Техпроцесс | 14 нм |

## 2. Технические характеристики

| Параметр | Значение |
|---|---|
| Ядра / потоки | 12 / 24 |
| Базовая частота | 3,00 ГГц |
| Макс. Turbo частота | 3,50 ГГц |
| L1 кэш | 512 КБ (инструкции) + 512 КБ (данные) |
| L2 кэш | 2 МБ |
| L3 кэш | 30 МБ |
| TDP | 160 Вт |
| Поддержка памяти | DDR4 2133/2400 МГц |
| Макс. объём памяти | 1,5 ТБ |
| Каналы памяти | 4 |
| Tjunction | 85 °C |

## 3. Поддержка технологий

- Intel Hyper-Threading
- Intel Turbo Boost 2.0
- Intel VT-x / VT-d
- Intel AES-NI
- Intel TSX
- Intel AVX2 / AVX-512 (не поддерживается)

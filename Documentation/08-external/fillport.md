# FREZE-MOD BT-2LY — Фитинг

Переходной фитинг для подключения шлангов к резьбовому порту.

- **Количество**: 12 шт.
- **Резьба**: G1/4
- **Наружный ∅ трубного конца**: 11 мм (шланг 9–10 мм)
- **Внутренний ∅**: 8.4 мм
- **Длина**: 25 мм (15.5 + 4.5 + 5.0 резьба G1/4)
- **Под ключ**: 17 мм
- **Масса**: ~9 г

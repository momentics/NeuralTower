# Thermaltake TOUGHFAN 12 — Вентилятор

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Модель | Thermaltake TOUGHFAN 12 |
| Тип | 120 мм вентилятор для радиатора |
| Производитель | Thermaltake |

## 2. Технические характеристики

| Параметр | Значение |
|---|---|
| Размеры | 120 × 120 × 25 мм |
| Воздушный поток | 58,35 CFM (99,1 м³/ч) |
| Статическое давление | 2,41 мм H₂O (23,63 Па) |
| Скорость вращения | до 2000 об/мин |
| Питание | 12 В DC (4-pin PWM) |
| Подключение | 4-pin PWM |

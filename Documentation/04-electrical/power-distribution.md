# Распределение питания между блоками Chieftec Polaris Pro 1300W

В системе используются два блока питания Chieftec Polaris Pro 1300W. Задача схемы — распределить нагрузку как можно ровнее и не использовать самодельные силовые переходники. Все силовые подключения выполняются штатными или покупными совместимыми кабелями.

CPU 8-pin входы мезонинов описаны отдельно: [adapter-spec.md](./adapter-spec.md).

## Состав потребителей

В системе два мезонина SXM2. На каждом мезонине стоят две NVIDIA Tesla V100.

Каждый мезонин имеет пять силовых входов:

- 2 x GPU 8-pin;
- 2 x CPU 8-pin;
- 1 x ATX 24-pin (не используется в текущей конфигурации);

Итого для двух мезонинов:

| Питание | На один мезонин | На два мезонина |
| --- | ---: | ---: |
| ATX 24-pin | 0 | 0 |
| GPU 8-pin | 2 | 4 |
| CPU 8-pin | 2 | 4 |

Материнская плата использует один ATX 24-pin, два CPU 8-pin и один PCIe 6-pin (расположен почти в центре платы).

Также питаются:

| Потребитель | Количество |
| --- | ---: |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

## Расчет потребляемой мощности

Расчет ниже дан по DC-нагрузке на выходах БП. Это проектные значения. После сборки их нужно проверить ваттметрами на входах 230 В и показаниями мониторинга GPU.

| Потребитель | Количество | Расчет на единицу | Итого |
| --- | ---: | ---: | ---: |
| NVIDIA Tesla V100 SXM2 (PL 300W) | 4 | 300 Вт | 1200 Вт |
| Плата мезонина | 2 | 50 Вт | 100 Вт |
| Материнская плата ASUS X99-E WS | 1 | 50 Вт | 50 Вт |
| CPU Intel Xeon E5-2687W v4 | 1 | 160 Вт | 160 Вт |
| DDR4 ECC Registered 256GB (8x32GB) | 8 | 16 Вт | 128 Вт |
| SSD Intel DC P4510 1 TB | 1 | 15 Вт | 15 Вт |
| Помпа D5 | 2 | 22 Вт | 44 Вт |
| Вентиляторы радиаторов СЖО | 6 | 7.5 Вт | 45 Вт |
| **Итого расчетная DC-нагрузка** |  |  | **1742 Вт** |

`1742 Вт` — это расчетный максимум DC-потребления. Тепловая нагрузка внутри корпуса: 1652 Вт (1324 Вт в СЖО + 328 Вт в воздух). Разница ~90 Вт — потери на КПД БП, выходящие через вентиляторы БП наружу. Мощность двух Chieftec Polaris Pro 1300W = 2600 Вт, избыток 33%. Достаточно с запасом.

**Важно:** NVIDIA Tesla V100 SXM2 32GB имеет PL (Power Limit) 300W. Это максимальная мощность, которую может потреблять один чип V100 SXM2. Значение 450W является ошибочным и относится к другим моделям GPU.

| Сценарий | GPU | Платы мезонинов | Прочие потребители | Итого |
| --- | ---: | ---: | ---: | ---: |
| Расчетный максимум | 4 x 300 Вт = 1200 Вт | 2 x 50 Вт = 100 Вт | 442 Вт | 1742 Вт |

Нагрузку нужно балансировать по мощности, а не по числу разъемов.

Каждый Chieftec Polaris Pro 1300W питает один полный мезонин с двумя V100. Материнская плата подключена к ведущему БП. Чтобы снизить перекос, помпы и вентиляторы подключены к ведомому БП.

Стартовое распределение:

| Блок питания | Потребители | Пиковый расчет | Целевой длительный режим | IDLE |
| --- | --- | ---: | ---: | ---: |
| Ведущий Chieftec Polaris Pro 1300W | Материнская плата (50W), CPU (160W), RAM (128W), NVMe (15W), мезонин 1 с двумя V100 PL 300W и платой-носителем (650W) | 1003 W | ~903 W | ~365 W |
| Ведомый Chieftec Polaris Pro 1300W | Мезонин 2 с двумя V100 PL 300W и платой-носителем (650W), две D5 (44W), вентиляторы (45W) | 739 W | ~639 W | ~234 W |

**Примечание к целевому режиму:** При типичном инференсе GPU работают на 200–280W (не на пике 300W). При 250W/GPU Master = 50+160+128+15+550 = 903W, Slave = 550+44+45 = 639W. В IDLE GPU потребляют ~60W каждая, CPU/RAM снижают потребление.

После первого запуска нужно измерить потребление обоих БП на входах 230 В. Если под длительной нагрузкой разница больше `10–15%`, можно переносить только маломощные SATA/Molex/PWM-потребители.

Линии GPU 8-pin и CPU 8-pin мезонинов между БП не делятся.

## Маршрутизация кабелей

Кабели от БП маршрутизируются следующим образом:

1. От верха БП (Z=245 мм) поднимаются до палубного коридора (Z=245–260 мм)
2. Идут вверх через палубный коридор до материнской платы (Z=280–300 мм)
3. Для мезонинов кабели идут прямо вниз от верхней сервисной поперечины (Z=245 мм)

## Назначение блоков питания

Ведущий Chieftec Polaris Pro 1300W запускается от кнопки питания материнской платы и питает:

| Линия | Количество |
| --- | ---: |
| Материнская плата ATX 24-pin | 1 |
| Материнская плата CPU 8-pin | 2 |
| Материнская плата PCIe 6-pin | 1 | # Расположен почти в центре платы |
| Мезонин 1 ATX 24-pin | 0 |
| Мезонин 1 CPU 8-pin | 2 |
| Мезонин 1 GPU 8-pin | 2 |

Ведомый Chieftec Polaris Pro 1300W запускается через Add2PSU и питает:

| Линия | Количество |
| --- | ---: |
| Мезонин 2 ATX 24-pin | 0 |
| Мезонин 2 CPU 8-pin | 2 |
| Мезонин 2 GPU 8-pin | 2 |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

**Примечание:** Каждый мезонин требует 4 силовых подключения (2x GPU 8-pin, 2x CPU 8-pin). Мезонин 1 питается исключительно от ведущего БП, Мезонин 2 — от ведомого БП. Делить питание одного мезонина между двумя БП нельзя.

## Кабели и хабы

Допустимые кабели и хабы:

| Задача | Допустимое решение |
| --- | --- |
| ATX 24-pin материнской платы | Штатный кабель Chieftec Polaris Pro 1300W |
| CPU 8-pin материнской платы | Штатные кабели Chieftec Polaris Pro 1300W (8-pin + 4+4-pin) |
| PCIe 6-pin материнской платы | Штатный кабель Chieftec Polaris Pro 1300W (6+2-pin) |
| CPU 8-pin мезонинов | Штатные кабели Chieftec Polaris Pro 1300W (8-pin + 4+4-pin), без Y-разветвителей |
| GPU 8-pin мезонинов | Штатные кабели Chieftec Polaris Pro 1300W (6+2-pin), без Y-разветвителей |
| Помпы D5 и вентиляторы | Покупные SATA/Molex/PWM-хабы от ведомого Chieftec Polaris Pro 1300W |

Самодельные переходники PCIe 8-pin -> CPU/EPS 8-pin не используются. Если для входа нет штатного или покупного совместимого кабеля, систему включать нельзя.

## Синхронизация запуска

Ведомый Chieftec Polaris Pro 1300W запускается через плату синхронизации Add2PSU HZ-0001. Любой свободный Molex кабель питания от ведущего БП подключается к входному разъёму Add2PSU. Когда ведущий БП успешно запускается и подает напряжение на выбранный кабель, Add2PSU активирует внутреннюю MOSFET-коммутацию, замыкая сигнальный вывод `PS-ON` 24-контактного разъёма ведомого БП на общий (GND). Ведомый БП запускается синхронно с ведущим.

Подробнее о Add2PSU: [../08-external/add2psu.md](../08-external/add2psu.md).

Каждый силовой вход мезонина подключается отдельным кабелем от своего Chieftec Polaris Pro 1300W. Это относится ко всем четырем входам мезонина: двум GPU 8-pin и двум CPU 8-pin.

Для GPU 8-pin и CPU 8-pin не используются Y-разветвители и последовательное питание двух входов одним кабелем.

Исключение - вентиляторы. Их можно питать через покупной PWM-хаб с отдельным питанием SATA/Molex.

CPU 8-pin входы мезонинов подключаются только штатными кабелями Chieftec Polaris Pro 1300W (8-pin или 4+4-pin). PCIe 8-pin кабели для этих входов не используются.

Корпуса обоих Chieftec Polaris Pro 1300W должны иметь надежный электрический контакт с рамой. Проверка земли описана в [grounding.md](./grounding.md).

Оба Chieftec Polaris Pro 1300W ставятся в боковые PSU-отсеки нижнего яруса. Они не находятся в центральном объеме КВД.

Вентилятор каждого БП работает по отдельному наружному контуру: боковой фильтр -> Chieftec Polaris Pro 1300W -> задний выхлоп. Этот поток не используется для охлаждения материнской платы, мезонинов или радиаторов СЖО.

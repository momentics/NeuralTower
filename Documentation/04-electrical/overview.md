# Обзор электросхемы NeuralTower

Электрическая система NeuralTower построена на двух независимых блоках питания с принудительным уравниванием потенциалов и строгой маршрутизацией силовых и сигнальных кабелей.

## Распределение питания

В системе используются два блока питания Chieftec Polaris Pro 1300W, подключённых по схеме Master/Slave:

| Блок питания | Роль | Пиковая нагрузка | Целевой режим | IDLE |
| --- | --- | ---: | ---: | ---: |
| Ведущий (Master) | Материнская плата, CPU, RAM, NVMe, мезонин 1 (2× V100) | 1003 W | ~903 W | ~365 W |
| Ведомый (Slave) | Мезонин 2 (2× V100), помпы, вентиляторы | 735 W | ~625 W | ~220 W |

**Итого расчётная DC-нагрузка: 1638 Вт.** Мощность двух Chieftec Polaris Pro 1300W = 2600 Вт, избыток 37%.

Каждый мезонин питается исключительно от одного БП — делить питание одного мезонина между двумя БП нельзя.

Подробная маршрутизация: [power-distribution.md](./power-distribution.md).

## Синхронизация Add2PSU

Ведомый БП запускается через плату Add2PSU HZ-0001. Свободный Molex от ведущего БП подключается к входному разъёму Add2PSU; при подаче +12 В Add2PSU замыкает PS-ON ведомого БП на GND. Ведомый БП включается синхронно с ведущим.

Подробнее: [add2psu.md](../08-external/add2psu.md).

## Заземление

Оба БП крепятся к алюминиевому профилю каркаса через кронштейны из алюминия 6061-T6, обеспечивая гальваническую связь. Дополнительно корпуса соединены медным проводником 2,5 мм² (резервный путь). Корпус каждого БП должен иметь нулевое сопротивление с рамой.

Подробности: [grounding.md](./grounding.md).

## Топология SlimSAS

Каждый слот PCIe x16 материнской платы разветвляется через пассивный адаптер PCIe x16 -> 2× SlimSAS SFF-8654 на один GPU мезонина. Цветовая маркировка привязана к GPU:

```text
GPU 0 — красный
GPU 1 — синий
GPU 2 — зелёный
GPU 3 — жёлтый
```

Полная таблица соответствия: [slimsas-mapping.md](./slimsas-mapping.md).

## Спецификация переходников

CPU 8-pin входы мезонинов подключаются только штатными кабелями Chieftec Polaris Pro 1300W. Переходники PCIe 8-pin -> CPU/EPS 8-pin не используются.

Спецификация: [adapter-spec.md](./adapter-spec.md).

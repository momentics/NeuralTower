# Пропускная способность с учётом GPUDirect P2P и двух чипов PLX

Пропускная способность разделяется на два независимых контура: внутри мезонинов (через NVLink) и между мезонинами (через шину PCIe и чипы PLX).
Интерфейсы полнодуплексные, поэтому данные передаются одновременно в обоих направлениях.

## 1. Межмезонинный обмен и связь с CPU (PCIe 3.0 x16)
Каждая из четырёх карт V100 SXM2 подключена через адаптеры SlimSAS в режиме PCIe 3.0 x16.

- Односторонняя: теоретическая скорость PCIe 3.0 x16 составляет 16 ГБ/с. С учётом 128b/130b кодирования (оверхед 1,54%) реальная чистая скорость ≈ 15,75 ГБ/с на одну карту.
- Двунаправленная на одну карту: PCIe работает в полнодуплексном режиме, карта может одновременно отправлять 15,75 ГБ/с и принимать 15,75 ГБ/с. Суммарная пропускная способность одного адаптера составляет ~31,5 ГБ/с.
- Суммарный предел межмезонинного обмена (ограничение шины процессора):
  Плата ASUS X99-E WS подключена к единственному процессору Broadwell-EP через два коммутатора PLX PEX8747, каждый из которых забирает по 16 линий PCIe 3.0. Максимальная скорость обмена между Мезонином 1 и Мезонином 2 (или с системной ОЗУ/NVMe) ограничена шиной процессора:
  - Односторонняя: ~31,5 ГБ/с (15,75 ГБ/с через PLX1 + 15,75 ГБ/с через PLX2).
  - Двунаправленная: ~63 ГБ/с суммарно на всю систему.

------------------------------
## 2. Внутримезонинный обмен (NVLink 2.0)
Внутри каждого мезонина пары карт (GPU 0 $\leftrightarrow$ GPU 1 и GPU 2 $\leftrightarrow$ GPU 3) соединены напрямую через NVIDIA NVLink 2.0. Ускорители V100 SXM2 имеют по 6 каналов NVLink на чип.
В стандартных двухчиповых мезонинах V100 SXM2 карты соединены всеми шестью линками.

- Один канал NVLink 2.0: 25 ГБ/с односторонняя (50 ГБ/с двунаправленная).
- Суммарно на пару GPU (6 каналов):
  - Односторонняя: $6 \times 25 \text{ ГБ/с} = \mathbf{150 \text{ ГБ/с}}$.
  - Двунаправленная: $6 \times 50 \text{ ГБ/с} = \mathbf{300 \text{ ГБ/с}}$.

------------------------------

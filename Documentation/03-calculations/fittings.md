## ХОМУТЫ

Каждое соединение шланга с фитингом = 1 хомут. Итого: 37 хомутов + запас 10% = ~41 хомут.

## ДЛИНА ШЛАНГА

Оценка по маршрутам (оптимизированная трасса):
- Помпа1→Помпа2: ~80 мм
- Помпа2→CPU WB (вход): ~100 мм
- CPU WB→тройник (выход): ~100 мм
- Тройник→GPU0: ~80 мм
- GPU0→GPU1: ~120 мм
- GPU1→объединение: ~80 мм
- Тройник→GPU2: ~80 мм
- GPU2→GPU3: ~120 мм
- GPU3→объединение: ~80 мм
- Объединение→Радиатор1: ~150 мм
- Радиатор1→Радиатор2: ~120 мм
- Радиатор2→Помпа1: ~180 мм
- Fillport GPU (4×): ~520 мм (по 130 мм на каждый проход через палубу: 50 мм над палубой + 80 мм под палубой до тройника/объединения)
- Fillport CPU (2×): ~240 мм (по 120 мм на каждый проход через палубу: 100 мм вверх до CPU WB + 20 мм фитинг)
- Сливной кран: ~80 мм
- **Итого:** ~2650 мм + запас 30% = ~3445 мм

Расчёт: ~2650 мм + запас 30% = ~3445 мм. Закупка 3500 мм достаточна.

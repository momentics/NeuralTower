## Ключевые результаты

### Контур СЖО

- **Пиковая нагрузка:** 1324 Вт (4× GPU 285 Вт + CPU 140 Вт + помпы 44 Вт = 2×22 Вт)
- **ΔT теплоносителя:** 6.1 °C (пик), 5.0 °C (инференс)
- **Расход (рабочая точка 2× D5):** 3.5–4.0 л/мин (номинал 3.8), ΔP = 64–67 кПа (9.3–9.7 PSI)
- **T_КВД:** 44.4 °C (пик), 40.9 °C (инференс)
- **T_GPU:** 59–71 °C (пик), 53–64 °C (инференс)

### Воздушный контур

- **Пиковая нагрузка:** 328 Вт (GPU открытые зоны 60 Вт + бэкплейт CPU 20 Вт + VRM 120 Вт + RAM 128 Вт)
- **Расход воздуха:** 0.0566 м³/с (203.6 м³/ч)
- **Давление в КВД:** 20.9 Па
- **Скорость сопла мезонина:** 17.1 м/с
- **Скорость сопла VRM:** 15.4 м/с

### Критические узлы

1. **VRM материнской платы** — ёмкость теплосъёма 120 Вт, нагрузка 120 Вт (пик). **Запас: 0 Вт (0%)** — КРИТИЧЕСКИЙ узел. Рекомендуется мониторинг температуры и замена термопрокладок на фазопереходные (≥12 Вт/(м·К)).

2. **CPU бэкплейт** — критерий: равновесная температура (решение теплового баланса). Инференс (16 Вт): 73.4 °C, запас до лимита PCB (85 °C) +11.6 °C — режим покрыт. TDP (24 Вт): 87.3 °C по консервативной модели (Nu = 4.86 — нижняя граница) — рекомендуется мониторинг. PL2 (29 Вт): 95.8 °C — только кратковременно.

3. **Радиаторы СЖО** — площадь достаточна с большим запасом (ε ≈ 0.998 при геометрической площади ~5.8 м² на два радиатора; даже при консервативной A = 0.55 м²/радиатор вся нагрузка отводится). Нагрев воздуха на радиаторах 19.4 °C (пик) повышает T_КВД до 44.4 °C — ограничение системы по расходу воздуха.

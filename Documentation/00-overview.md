# NeuralTower

<img src="./Images/logo.png" width="100" align="left" alt="Логотип проекта NeuralTower"> Оригинальный инженерный проект настольной рабочей станции на четырёх NVIDIA Tesla V100 SXM2 32 GB (128 ГБ HBM2) для инференса больших моделей без зависимости от облака.
<br clear="left" />

## Проект

Доказательство концепции (PoC) успешно завершено: стенд из двух GPU V100 SXM2 32 ГБ на одном мезонине собран, протестирован и показал работоспособность всей цепочки PCIe-SlimSAS-GPU с инференсом модели Qwen3.6-27B на скорости 32,69 токена в секунду. Полноценная сборка на четырёх GPU с жидкостным охлаждением и двумя блоками питания находится в стадии подготовки. Тепловые, акустические и часть электрических выводов для полной конфигурации считаются расчётными до сборки финального узла.

**Критическое замечание по мощности:** NVIDIA Tesla V100 SXM2 32GB имеет PL (Power Limit) 300W. Все расчёты мощности и охлаждения выполнены с учётом этого ограничения. Водоблок Speedier XF-001-CO (300W TDP) полностью соответствует мощности GPU.

**Ключевые выводы пересчёта охлаждения (2026-07-24):**
- Пиковая нагрузка на СЖО: **1310W** (4×285W GPU + 140W CPU + 30W помпы). Расход 5.2 л/мин, ΔT теплоносителя 4.45 °C.
- Пиковая нагрузка на воздух: **328W**. Расход 0.0566 м³/с.
- Температура КВД: **44,2 °C** (пик), **40,7 °C** (инференс). Воздух нагревается на радиаторах СЖО на 19,2 °C.
- Температура выхлопа: **49,0 °C** (пик), **44,9 °C** (инференс).
- Запас по мезонинам: **+141,1 Вт (941%)** при пике.
- Запас по VRM MB: **0 Вт (0%)** при пике — ёмкость 120 Вт = нагрузка 120 Вт. КРИТИЧЕСКИЙ узел. При инференсе запас +30 Вт.
- Запас по CPU бэкплейту: **+14,6 °C** (до 85 °C PCB) при инференсе, **+6,8 °C** при TDP, **+3,3 °C** при PL2.
- Температуры GPU: **49,4–54,4 °C** (пик), **43,5–49,5 °C** (инференс).

## V-CORE

Схема охлаждения V-CORE: двухкамерная компоновка с нижним отсеком давления (КВД, 260 мм) и верхним вычислительным отсеком (264 мм). Жидкостный контур забирает тепло от GPU, радиаторы расположены в нижнем отсеке, воздушный поток проходит через радиаторы снизу вверх. Вкладная палуба 458×258 мм разделяет камеры.

Расчёты:
- [Аэродинамика](./03-calculations/air-dynamics.md) — воздушные потоки, температуры, скорости
- [Гидравлика](./03-calculations/coolant-hydraulics.md) — расход, давление, объём теплоносителя

## Что требует физической проверки

- Фактическая температура VRM под длительной нагрузкой.
- Температура HBM2 при многочасовом инференсе и дообучении.
- Реальная скорость воздушных потоков после сборки корпуса.
- Шум системы в настольном режиме.
- Устойчивость палубы к утечкам воздуха.
- Герметичность изолированных PSU-отсеков относительно КВД.
- Стабильность двух помп в выбранной гидравлической схеме.
- Корректная работа всех четырех V100 через PLX-коммутаторы.
- Стабильность GPUDirect P2P между мезонинами.
- Фактическая производительность на моделях класса 70B.
- Польза vLLM swap на реальных длинных контекстах.
- Поведение системы при отказе одной помпы или одного вентилятора.

## Минимальный план первичной проверки

1. Проверить питание без установленных GPU.
2. Проверить совместный старт двух БП через Add2PSU.
3. Проверить общую землю между корпусами БП и рамой.
4. Проверить, что вентиляторы Chieftec Polaris Pro 1300W забирают воздух только через боковые фильтры и не подсасывают воздух из КВД.
5. Проверить наружный доступ к выключателям и IEC-разъёмам Chieftec Polaris Pro 1300W.
6. Проверить герметичность уплотнения КВД и изоляцию воздушного потока БП.
7. Провести тест герметичности контура СЖО под давлением.
8. Проверить работоспособность и производительность помп D5.

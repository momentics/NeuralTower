# Обзор механической конструкции NeuralTower

## Корпус

| Параметр | Значение |
| --- | --- |
| Внутренний размер | 500 x 300 x 524 мм |
| Внешний размер рамы | 540 x 340 x 564 мм |
| Внешний размер с ножками 40 мм | 540 x 340 x 604 мм |
| Профиль | Алюминий 20 x 20 мм, T-паз 6 мм |
| Палубный пояс | Z = 260 мм |
| Вкладная палуба | АМг3, 458 x 258 x 3 мм |

Нижний отсек (Z = 0–260 мм) — герметичная камера высокого давления (КВД) с радиаторами СЖО, помпами и боковыми PSU-отсеками. Верхний отсек (Z = 260–524 мм) — вычислительный ярус с материнской платой на стойках 45 мм и двумя мезонинами V100.

## Система координат

Нулевая точка `X = 0`, `Y = 0`, `Z = 0` — нижний передний левый внутренний угол рамы.

| Ось | Направление | Диапазон |
| --- | --- | --- |
| X | Слева направо (ширина) | 0–500 мм |
| Y | От передней панели к задней (глубина) | 0–300 мм |
| Z | Снизу вверх (высота) | 0–524 мм |

Для отверстий и вырезов палубы используется локальная сетка листа `Xd = X − 21`, `Yd = Y − 21`.

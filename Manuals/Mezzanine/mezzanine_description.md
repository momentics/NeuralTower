# Техническое описание мезонинной платы SXM2 (V100)

## 1. Общие сведения

Мезонинная плата предназначена для установки двух GPU-модулей NVIDIA Tesla V100 в форм-факторе SXM2.0. Плата устанавливается между материнской платой и корпусом, обеспечивая питание, управление питанием и высокоскоростные данные для GPU-модулей.

## 2. Габаритные размеры

| Параметр | Значение |
|----------|----------|
| Длина (ось X) | 236 мм |
| Ширина (ось Y) | 170 мм |
| Источник | Диаграмма производителя |

## 3. Слоты SXM2

| Параметр | Значение |
|----------|----------|
| Количество | 2 |
| Тип | SXM2.0 |
| Совместимые модули | NVIDIA Tesla V100 SXM2 |
| Расположение | Вертикальное, один над другим вдоль оси 170 мм |

На шелкографии вблизи каждого слота нанесена маркировка «V100».

## 4. Разъёмы питания (правый край платы, сверху вниз)

| № | Разъём | Кол-во | Назначение |
|---|--------|--------|------------|
| 1 | ATX 24-pin | 1 | Основное питание платы (обязательный по спецификации производителя) |
| 2 | CPU 8-pin (EPS 12V) | 2 | Дополнительное питание |
| 3 | GPU 8-pin (PCIe 12V) | 2 | Дополнительное питание |

### Требования к подключению

- Разъём ATX 24-pin является обязательным для запуска платы согласно спецификации производителя. Без подключения платы не начнёт работу. В конфигурации NeuralTower 24-pin не подключён, так как сигнал включения 12V обеспечивается через общий БП (мезонин 1) и Add2PSU (мезонин 2).
- Из четырёх разъёмов CPU/GPU 8-pin необходимо подключить минимум 2. Допускается подключение большего количества.
- Разъёмы типов CPU (EPS) и GPU (PCIe) могут комбинироваться произвольно.

> **Примечание по конфигурации NeuralTower:**
>
> В NeuralTower разъём ATX 24-pin на мезонинах не подключён. ATX 24-pin на этой плате служит сигналом включения 12V. Мезонин 1 питается от того же БП, что и материнская плата — БП уже включён материнской. Мезонин 2 питается от ведомого БП, который запускается через Add2PSU (замыкание PS-ON на GND). Оба мезонина получают 12V без подключения 24-pin.

## 5. Разъёмы данных (левый край платы)

| Параметр | Значение |
|----------|----------|
| Тип разъёма | SFF-8654-8i |
| Общее количество | 4 |
| Группировка | 2 разъёма = 1 группа = 1 GPU V100 |
| Пропускная способность группы | x16 (полная ширина для одного GPU) |
| Пропускная способность одного разъёма в группе | x8 |

Каждая из двух групп по два разъёма обеспечивает полное подключение x16 к соответствующему GPU-модулю V100.

## 6. Переключатели управления питанием (правый край, над блоком питания)

### DIP-переключатель AT/MT

| Позиция | Режим | Описание |
|---------|-------|----------|
| MT | Ручной режим | Питание платы управляется кнопкой ON/OFF независимо от материнской платы |
| AT | Автоматический режим | Питание платы следует за состоянием материнской платы: MB включена → плата включена, MB выключена → плата выключена |

### Кнопка ON/OFF

| Параметр | Значение |
|----------|----------|
| Функция | Включение/выключение питания платы |
| Активна | Только в режиме MT |
| Позиция ON | Питание включено |
| Позиция OFF | Питание выключено |
| В режиме AT | Неактивна (игнорируется) |

> **Рекомендация для NeuralTower:** Использовать режим AT, при котором питание мезонинной платы синхронизировано с питанием материнской платы.

## 7. Крепёжные отверстия

| Параметр | Значение |
|----------|----------|
| Количество | 4 |
| Расположение | По углам платы |
| Покрытие | Золотое (gold-plated) |

## 8. Шелкография и маркировка

- **«V100»** — обозначение вблизи слотов SXM2
- **«VR»** — маркировка зоны VRM (Voltage Regulator Module)
- **CE / FCC** — знаки соответствия требованиям сертификации
- **Серийный номер** — выделенная область для наклейки с серийным номером платы

## 10. Примечания по интеграции в NeuralTower

1. **Режим питания:** Для корректной работы в составе NeuralTower DIP-переключатель должен быть установлен в положение **AT** (автоматический режим).
2. **ATX 24-pin:** Не подключён. Сигнал включения 12V обеспечивается через общий БП (мезонин 1) и Add2PSU (мезонин 2).
3. **Минимальное питание:** Подключены как минимум 2 из 4 разъёмов CPU/GPU 8-pin. Рекомендуется подключить все 4 для обеспечения достаточной мощности при полной загрузке обоих GPU V100.

# Техническое описание водоблока Speedier XF-001-CO

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Модель | Speedier XF-001-CO |
| Назначение | Водяная охлаждающая головка для GPU NVIDIA V100 (SXM2) |
| Заявленная тепловая мощность | 300 Вт (TDP) |
| Производитель | Speedier |

## 2. Габаритные размеры

| Параметр | Значение |
|---|---|
| Длина | 140 мм |
| Ширина | 80 мм |
| Толщина (высота блока) | 30 мм |
| Общий габарит | 140 × 80 × 30 мм |

## 3. Конструкция

### 3.1. Тело водоблока

- **Теплоотводящая пластина (cold plate):** массивная медная основа с микроребристой структурой каналов, видимой через прозрачную верхнюю крышку. Микроребра обеспечивают увеличенную площадь теплообмена и турбулизацию потока охлаждающей жидкости.
- **Верхняя крышка:** прозрачная акриловая/полимерная панель, позволяющая визуально контролировать течение жидкости и обнаруживать воздушные пробки.
- **Крепление крышки:** 4 винта с крестовым шлицем (Phillips/十字), фиксирующие акриловую крышку к медному основанию.

### 3.2. Задняя пластина-распределитель

- Алюминиевая задняя пластина (backplate/spreader), выступающая за габариты самого водоблока.
- Пластина перекрывает зону VRM (модуль регулирования напряжения), расположенную рядом с GPU на плате-носителе, обеспечивая дополнительный отвод тепла от силовой электроники.

### 3.3. Подводные фитинги

| Параметр | Значение |
|---|---|
| Резьба | G1/4 |
| Тип | Компрессионный (compression fitting) |
| Совместимый шланг | EPDM 10/16 мм (внутренний/наружный диаметр) |
| Количество | 2 штуки |
| Расположение | На одной стороне блока, на верхней грани |
| Выступ над блоком | ~15–20 мм над верхней поверхностью (30 мм) |

Фитинги расположены на одной стороне водоблока, что обеспечивает возможность последовательного подключения нескольких блоков в цепочку.

## 4. Тепловые характеристики

- **Максимальная рассеиваемая мощность:** 300 Вт (согласно маркировке производителя).
- Медная теплоотводящая пластина с микроребрами обеспечивает эффективный отвод тепла от чипа GPU.
- Алюминиевая задняя пластина дополнительно отводит тепло от зоны VRM.

## 5. Установка на межсоединительную плату (mezzanine)

### 5.1. Конфигурация

- Водоблок предназначен для установки на плату-носитель с двумя GPU NVIDIA V100 SXM2.
- На каждый GPU V100 устанавливается один водоблок XF-001-CO.
- Блоки подключаются последовательно: выход первого блока соединяется со входом второго.

### 5.2. Ориентация фитингов

- Фитинги ориентированы в сторону (на боковую грань), что позволяет прокладывать шланги вдоль края межсоединительной платы.
- Алюминиевая пластина-распределитель перекрывает зону VRM, смежную с GPU.

## 6. Критические размеры для интеграции в NeuralTower

| Параметр | Значение |
|---|---|
| Высота водоблока | 30 мм |
| Общая высота с фитингами | ~45–50 мм (выступ над поверхностью межсоединительной платы) |
| Лимит зазора в верхнем отсеке | 54 мм (зазор от верхней кромки мезонина до крышки) |
| Оставшийся запас для изгиба шланга | ~4–9 мм над фитингами; при высоте мезонина 170 мм и верхнем отсеке 264 мм шланги имеют достаточное пространство для вывода вверх |

### 6.1. Примечание по зазору

Запас 4–9 мм над фитингами для радиуса изгиба шланга в верхней части отсека. При высоте мезонина 170 мм и верхнем отсеке 264 мм шланги СЖО имеют достаточное пространство для вывода вверх без перегиба. При монтаже необходимо:

1. Использовать шланги с минимально возможным радиусом изгиба.
2. Тщательно планировать трассировку шлангов для избежания перегибов и избыточного падения давления.
3. Учитывать допуски на установку межсоединительной платы и возможные отклонения положения водоблоков.

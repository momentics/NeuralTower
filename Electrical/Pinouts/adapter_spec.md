# Подключение CPU 8-pin входов мезонинов

На каждом мезонине есть два GPU 8-pin и два CPU 8-pin входа. Этот файл описывает только два CPU 8-pin входа мезонина.

CPU 8-pin входы мезонинов подключаются только штатными или покупными совместимыми Corsair Type 4 CPU/EPS кабелями от своего HX1500i. Переходники PCIe 8-pin -> CPU/EPS 8-pin не используются.

Модульные кабели должны быть совместимы именно с Corsair HX1500i / Type 4. Кабели от других БП не используются, даже если физически подходят к разъему.

**Внимание:** Объединение линии +12 В от двух HX1500i недопустимо — возникнут паразитные токи между блоками питания. Все входы одного мезонина питаются от одного HX1500i.

**Проверка:** Сопротивление между GND кабеля и корпусом соответствующего HX1500i должно быть близким к нулю для бытового мультиметра. Кабель можно подключать к мезонину только после проверки всех четырёх контактов +12 В и всех четырёх контактов GND.

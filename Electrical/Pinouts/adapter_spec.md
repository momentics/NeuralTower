# Подключение CPU 8-pin входов мезонинов

На каждом мезонине есть один ATX 24-pin, два GPU 8-pin и два CPU 8-pin входа. Этот файл описывает только два CPU 8-pin входа мезонина.

CPU 8-pin входы мезонинов подключаются только штатными или покупными совместимыми Corsair Type 4 CPU/EPS кабелями от своего HX1000. Переходники PCIe 8-pin -> CPU/EPS 8-pin не используются.

Распределение нагрузки между БП описано в [../Wiring/power_distribution.md](../Wiring/power_distribution.md).

## Назначение

В системе два мезонина SXM2. На каждом мезонине есть два CPU 8-pin входа. Всего нужно четыре CPU 8-pin кабеля.

Все четыре подключения выполняются без перепиновки.

PCIe 8-pin и CPU 8-pin похожи внешне, но имеют разную распиновку. PCIe 8-pin кабель нельзя подключать в CPU 8-pin вход мезонина. Это может привести к короткому замыканию или подать +12 V на землю.

Модульные кабели должны быть совместимы именно с Corsair HX1000 / Type 4. Кабели от других БП не используются, даже если физически подходят к разъему.

## Требуемое состояние разъема

Проверка выполняется мультиметром. Ориентир - фактическое напряжение на контактах, а не цвет провода.

CPU 8-pin вход мезонина должен иметь:

| Сторона CPU 8-pin | Требуемый потенциал |
| --- | --- |
| 4 контакта со стороны защелки | +12 V |
| 4 контакта с противоположной стороны | GND |

Нумерацию контактов нужно проверять по конкретному разъему или даташиту. Схемы могут показывать вид со стороны проводов или со стороны контактов. Поэтому визуальная схема не заменяет прозвонку.

## Запрещенные подключения

| Запрещено | Причина |
| --- | --- |
| PCIe 8-pin кабель в CPU 8-pin вход | Другая распиновка |
| Переходник PCIe 8-pin -> CPU/EPS 8-pin | Не используется в этой схеме |
| Модульный кабель от другого производителя | Распиновка на стороне БП не универсальна |
| Ручная перепиновка Corsair Type 4 | Нет заводской проверки |
| Объединение +12 V от двух HX1000 | Возможны токи между БП |

Все входы одного мезонина питаются от одного HX1000.

## Проверка перед подключением

Перед подключением к мезонину каждый CPU 8-pin кабель проверяется мультиметром.

| Проверка | Ожидаемый результат |
| --- | --- |
| Прозвонка +12 V -> GND при выключенном БП | Короткого замыкания нет |
| CPU 8-pin, контакты со стороны защелки | +12 V при включенном БП |
| CPU 8-pin, противоположная сторона | GND |
| Сопротивление между GND кабеля и корпусом соответствующего HX1000 | Близко к нулю для бытового мультиметра |

Кабель можно подключать к мезонину только после проверки всех четырех контактов +12 V и всех четырех контактов GND.

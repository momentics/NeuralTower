# Подключение CPU 8-pin входов мезонинов

На каждом мезонине есть два GPU 8-pin и два CPU 8-pin входа. Этот файл описывает только два CPU 8-pin входа мезонина.

CPU 8-pin входы мезонинов подключаются только штатными кабелями EDGE 1300W (8-pin или 4+4-pin) от своего БП. Переходники PCIe 8-pin -> CPU/EPS 8-pin не используются.

Модульные кабели должны быть совместимы именно с Lian Li EDGE 1300W. Кабели от других БП не используются, даже если физически подходят к разъему.

**Внимание:** Объединение линии +12 В от двух EDGE 1300W недопустимо — возникнут паразитные токи между блоками питания. Все входы одного мезонина питаются от одного EDGE 1300W.

**Проверка:** Сопротивление между GND кабеля и корпусом соответствующего EDGE 1300W должно быть близким к нулю для бытового мультиметра. Кабель можно подключать к мезонину только после проверки всех четырёх контактов +12 В и всех четырёх контактов GND.

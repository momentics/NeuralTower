# Распределение питания между блоками HX1500i

В системе используются два блока питания Corsair HX1500i. Задача схемы - распределить нагрузку как можно ровнее и не использовать самодельные силовые переходники. Все силовые подключения выполняются штатными или покупными совместимыми кабелями.

CPU 8-pin входы мезонинов описаны отдельно: [../Pinouts/adapter_spec.md](../Pinouts/adapter_spec.md).

## Состав потребителей

В системе два мезонина SXM2. На каждом мезонине стоят две NVIDIA Tesla V100.

Каждый мезонин имеет пять силовых входов:

- 2 x GPU 8-pin;
- 2 x CPU 8-pin.
- 1 x ATX 24-pin (не используется в текущей конфигурации);

Итого для двух мезонинов:

| Питание | На один мезонин | На два мезонина |
| --- | ---: | ---: |
| ATX 24-pin | 0 | 0 |
| GPU 8-pin | 2 | 4 |
| CPU 8-pin | 2 | 4 |

Материнская плата использует один ATX 24-pin, два CPU 8-pin и один PCIe 6-pin.

Также питаются:

| Потребитель | Количество |
| --- | ---: |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

## Расчет потребляемой мощности

Расчет ниже дан по DC-нагрузке на выходах БП. Это проектные значения. После сборки их нужно проверить ваттметрами на входах 230 В и показаниями мониторинга GPU.

| Потребитель | Количество | Расчет на единицу | Итого |
| --- | ---: | ---: | ---: |
| NVIDIA Tesla V100 SXM2 (PL 450W) | 4 | 450 Вт | 1800 Вт |
| Плата мезонина | 2 | 50 Вт | 100 Вт |
| Материнская плата ASUS X99-E WS | 1 | 50 Вт | 50 Вт |
| CPU Intel Xeon E5-2699v4 | 1 | 145 Вт | 145 Вт |
| DDR4 ECC Registered 256GB (8x32GB) | 8 | 16 Вт | 128 Вт |
| SSD Intel DC P4510 1 TB | 1 | 15 Вт | 15 Вт |
| Помпа D5 | 2 | 15 Вт | 30 Вт |
| Вентиляторы радиаторов СЖО | 6 | 7.5 Вт | 45 Вт |
| **Итого расчетная DC-нагрузка** |  |  | **2213 Вт** |

`2213 Вт` - это расчетный максимум. Мощность двух HX1500i = 3000 Вт, избыток 26%. Достаточно с запасом.

| Сценарий | GPU | Прочие потребители | Итого |
| --- | ---: | ---: | ---: |
| Расчетный максимум | 4 x 450 Вт = 1800 Вт | 413 Вт | 2213 Вт |

Нагрузку нужно балансировать по мощности, а не по числу разъемов.

Каждый HX1500i питает один полный мезонин с двумя V100. Материнская плата подключена к ведущему БП. Чтобы снизить перекос, помпы и вентиляторы подключены к ведомому БП.

Стартовое распределение:

| Блок питания | Потребители | Максимальный расчет | Целевой длительный режим |
| --- | --- | ---: | ---: |
| Ведущий HX1500i | Материнская плата (50W), CPU (145W), RAM (128W), NVMe (15W), мезонин 1 с двумя V100 (900W) | 1238 W | 1038 W |
| Ведомый HX1500i | Мезонин 2 с двумя V100 (900W), две D5 (30W), вентиляторы (45W) | 975 W | 975 W |

После первого запуска нужно измерить потребление обоих БП на входах 230 В. Если под длительной нагрузкой разница больше `10-15%`, можно переносить только маломощные SATA/Molex/PWM-потребители.

Линии GPU 8-pin и CPU 8-pin мезонинов между БП не делятся.

## Маршрутизация кабелей

Кабели от БП маршрутизируются следующим образом:

1. От верха БП (Z=245 мм) поднимаются до палубного коридора (Z=245–260 мм)
2. Идут вверх через палубный коридор до материнской платы (Z=280–300 мм)
3. Для мезонинов кабели идут прямо вниз от верхней сервисной поперечи (Z=245 мм)

## Назначение блоков питания

Ведущий HX1500i запускается от кнопки питания материнской платы и питает:

| Линия | Количество |
| --- | ---: |
| Материнская плата ATX 24-pin | 1 |
| Материнская плата CPU 8-pin | 2 |
| Материнская плата PCIe 6-pin | 1 |
| Мезонин 1 ATX 24-pin | 0 |
| Мезонин 1 CPU 8-pin | 2 |
| Мезонин 1 GPU 8-pin | 2 |

Ведомый HX1500i запускается через Add2PSU и питает:

| Линия | Количество |
| --- | ---: |
| Мезонин 2 ATX 24-pin | 0 |
| Мезонин 2 CPU 8-pin | 2 |
| Мезонин 2 GPU 8-pin | 2 |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

**Примечание:** Каждый мезонин требует 4 силовых подключения (2x GPU 8-pin, 2x CPU 8-pin). Мезонин 1 питается исключительно от ведущего БП, Мезонин 2 - от ведомого БП. Делить питание одного мезонина между двумя БП нельзя.

## Кабели и хабы

Допустимые кабели и хабы:

| Задача | Допустимое решение |
| --- | --- |
| ATX 24-pin материнской платы | Штатный кабель Corsair HX1500i |
| CPU 8-pin материнской платы | Штатные или совместимые Corsair Type 4 CPU/EPS кабели |
| PCIe 6-pin материнской платы | Штатный или совместимый Corsair Type 4 PCIe кабель |
| CPU 8-pin мезонинов | Штатные или совместимые Corsair Type 4 CPU/EPS кабели, без Y-разветвителей |
| GPU 8-pin мезонинов | Штатные или совместимые Corsair Type 4 PCIe кабели, без Y-разветвителей |
| Помпы D5 и вентиляторы | Покупные SATA/Molex/PWM-хабы от ведомого HX1500i |

Самодельные переходники PCIe 8-pin -> CPU/EPS 8-pin не используются. Если для входа нет штатного или покупного совместимого кабеля, систему включать нельзя.

## Синхронизация запуска

Ведомый HX1500i запускается через плату синхронизации Add2PSU. Для исключения ложных срабатываний из-за дребезга контактов и помех управляющий вход платы Add2PSU подключается к сигналу PWR_OK (pin 8) ведущего БП через сглаживающий LC-фильтр (подробное описание и расчет параметров фильтра приведены в [LC_filter.md](../../Docs/Calculations/LC_filter.md)). Когда ведущий БП успешно запускается и стабилизирует напряжение, сигнал PWR_OK через фильтр активирует Add2PSU, которая замыкает управляющие контакты (PS_ON) ведомого БП.

Каждый силовой вход мезонина подключается отдельным кабелем от своего HX1500i. Это относится ко всем четырем входам мезонина: двум GPU 8-pin и двум CPU 8-pin.

Для GPU 8-pin и CPU 8-pin не используются Y-разветвители и последовательное питание двух входов одним кабелем.

Исключение - вентиляторы. Их можно питать через покупной PWM-хаб с отдельным питанием SATA/Molex.

CPU 8-pin входы мезонинов подключаются только штатными или покупными совместимыми Corsair Type 4 CPU/EPS кабелями. PCIe 8-pin кабели для этих входов не используются.

Корпуса обоих HX1500i должны иметь надежный электрический контакт с рамой. Проверка земли описана в [grounding_guide.md](grounding_guide.md).

Оба Corsair HX1500i ставятся в боковые PSU-отсеки нижнего яруса. Они не находятся в центральном объеме КВД.

Вентилятор каждого БП работает по отдельному наружному контуру: боковой фильтр -> HX1500i -> задний выхлоп. Этот поток не используется для охлаждения материнской платы, мезонинов или радиаторов СЖО.

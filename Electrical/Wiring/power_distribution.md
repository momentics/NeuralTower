# Распределение питания между блоками HX1000

В системе используются два блока питания Corsair HX1000. Задача схемы - распределить нагрузку как можно ровнее и не использовать самодельные силовые переходники. Все силовые подключения выполняются штатными или покупными совместимыми кабелями.

CPU 8-pin входы мезонинов описаны отдельно: [../Pinouts/adapter_spec.md](../Pinouts/adapter_spec.md).

## Состав потребителей

В системе два мезонина SXM2. На каждом мезонине стоят две NVIDIA Tesla V100.

Каждый мезонин имеет пять силовых входов:

- 1 x ATX 24-pin;
- 2 x GPU 8-pin;
- 2 x CPU 8-pin.

Итого для двух мезонинов:

| Питание | На один мезонин | На два мезонина |
| --- | ---: | ---: |
| ATX 24-pin | 1 | 2 |
| GPU 8-pin | 2 | 4 |
| CPU 8-pin | 2 | 4 |

Материнская плата использует один ATX 24-pin, два CPU 8-pin и один PCIe 6-pin.

Также питаются:

| Потребитель | Количество |
| --- | ---: |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

## Расчет потребляемой мощности

Расчет ниже дан по DC-нагрузке на выходах БП. Это проектные значения. После сборки их нужно проверить ваттметрами на входах 230 V и показаниями мониторинга GPU.

| Потребитель | Количество | Расчет на единицу | Итого |
| --- | ---: | ---: | ---: |
| NVIDIA Tesla V100 SXM2 | 4 | 300 W | 1200 W |
| Плата мезонина | 2 | 50 W | 100 W |
| Материнская плата ASUS X99-E WS, CPU, RAM, NVMe и периферия | 1 | 220 W | 220 W |
| Помпа D5 | 2 | 25 W | 50 W |
| Вентилятор радиатора | 6 | 5 W | 30 W |
| **Итого расчетная DC-нагрузка** |  |  | **1600 W** |

`1600 W` - это расчетный максимум. Для длительной работы это слишком близко к верхней зоне нагрузки двух HX1000. Рабочий режим для инференса: ограничить каждую V100 до `250 W` через `nvidia-smi`. Тогда расчетная нагрузка системы снижается до `1400 W`.

| Сценарий | GPU | Прочие потребители | Итого |
| --- | ---: | ---: | ---: |
| Максимальный расчет | 4 x 300 W = 1200 W | 400 W | 1600 W |
| Целевой длительный режим | 4 x 250 W = 1000 W | 400 W | 1400 W |

## Принцип балансировки

Нагрузку нужно балансировать по мощности, а не по числу разъемов.

Каждый HX1000 питает один полный мезонин с двумя V100. Материнская плата подключена к ведущему БП. Чтобы снизить перекос, помпы и вентиляторы подключены к ведомому БП.

Стартовое распределение:

| Блок питания | Потребители | Максимальный расчет | Целевой длительный режим |
| --- | --- | ---: | ---: |
| Ведущий HX1000 | Материнская плата, CPU, RAM, NVMe, мезонин 1 с двумя V100 | 870 W | 770 W |
| Ведомый HX1000 | Мезонин 2 с двумя V100, две D5, шесть вентиляторов | 730 W | 630 W |

После первого запуска нужно измерить потребление обоих БП на входах 230 V. Если под длительной нагрузкой разница больше `10-15%`, можно переносить только маломощные SATA/Molex/PWM-потребители. Линии GPU 8-pin, CPU 8-pin и ATX 24-pin мезонинов между БП не делятся.

## Назначение блоков питания

Ведущий HX1000 запускается от кнопки питания материнской платы и питает:

| Линия | Количество |
| --- | ---: |
| Материнская плата ATX 24-pin | 1 |
| Материнская плата CPU 8-pin | 2 |
| Материнская плата PCIe 6-pin | 1 |
| Мезонин 1 ATX 24-pin | 1 |
| Мезонин 1 CPU 8-pin | 2 |
| Мезонин 1 GPU 8-pin | 2 |

Ведомый HX1000 запускается через Add2PSU и питает:

| Линия | Количество |
| --- | ---: |
| Мезонин 2 ATX 24-pin | 1 |
| Мезонин 2 CPU 8-pin | 2 |
| Мезонин 2 GPU 8-pin | 2 |
| Помпы D5 | 2 |
| Вентиляторы радиаторов СЖО | 6 |

Один мезонин питается только от одного HX1000. Делить питание одного мезонина между двумя БП нельзя.

## Кабели и хабы

Допустимые кабели и хабы:

| Задача | Допустимое решение |
| --- | --- |
| ATX 24-pin материнской платы | Штатный кабель Corsair HX1000 |
| CPU 8-pin материнской платы | Штатные или совместимые Corsair Type 4 CPU/EPS кабели |
| PCIe 6-pin материнской платы | Штатный или совместимый Corsair Type 4 PCIe кабель |
| ATX 24-pin мезонинов | Покупной ATX 24-pin кабель/удлинитель/переходная плата, рассчитанные на нужные линии и ток |
| GPU 8-pin мезонинов | Штатные или совместимые Corsair Type 4 PCIe кабели, без Y-разветвителей |
| CPU 8-pin мезонинов | Штатные или совместимые Corsair Type 4 CPU/EPS кабели |
| Помпы D5 и вентиляторы | Покупные SATA/Molex/PWM-хабы от ведомого HX1000 |

Самодельные переходники PCIe 8-pin -> CPU/EPS 8-pin не используются. Если для входа нет штатного или покупного совместимого кабеля, систему включать нельзя.

## Синхронизация запуска

Ведомый HX1000 запускается через плату синхронизации Add2PSU. Для исключения ложных срабатываний из-за дребезга контактов и помех управляющий вход платы Add2PSU подключается к сигналу PWR_OK (pin 8) ведущего БП через сглаживающий LC-фильтр (подробное описание и расчет параметров фильтра приведены в [LC_filter.md](../../Docs/Calculations/LC_filter.md)). Когда ведущий БП успешно запускается и стабилизирует напряжение, сигнал PWR_OK через фильтр активирует Add2PSU, которая замыкает управляющие контакты (PS_ON) ведомого БП.

Перед эксплуатацией нужно проверить порядок запуска. Ведомый БП должен включаться до вычислительной нагрузки на втором мезонине. Если второй мезонин получает PCIe-сигналы до появления питания, схему запуска нужно исправить.

## Разводка кабелей

Каждый силовой вход мезонина подключается отдельным кабелем от своего HX1000. Это относится ко всем пяти входам мезонина: одному ATX 24-pin, двум GPU 8-pin и двум CPU 8-pin.

Для GPU 8-pin, CPU 8-pin и ATX 24-pin не используются Y-разветвители и последовательное питание двух входов одним кабелем.

Исключение - вентиляторы. Их можно питать через покупной PWM-хаб с отдельным питанием SATA/Molex.

CPU 8-pin входы мезонинов подключаются только штатными или покупными совместимыми Corsair Type 4 CPU/EPS кабелями. PCIe 8-pin кабели для этих входов не используются.

Корпуса обоих HX1000 должны иметь надежный электрический контакт с рамой. Проверка земли описана в [grounding_guide.md](grounding_guide.md).

## Механическая ориентация БП и ввод 230 V

Оба Corsair HX1000 ставятся в боковые PSU-отсеки нижнего яруса. Они не находятся в центральном объеме КВД.

| БП | Зона установки |
| --- | --- |
| Левый | `X = 0-86 мм`, `Y = 115-300 мм`, `Z = 95-245 мм` |
| Правый | `X = 414-500 мм`, `Y = 115-300 мм`, `Z = 95-245 мм` |

Сторона с IEC C14, выключателем и выхлопной решеткой смотрит к задней панели корпуса. Кабели 230 V подключаются снаружи и не заводятся внутрь корпуса.

Модульная сторона БП смотрит внутрь, к сервисной зоне. DC-кабели сразу фиксируются на кабельной планке под палубой.

Вентилятор каждого БП работает по отдельному наружному контуру: боковой фильтр -> HX1000 -> задний выхлоп. Этот поток не используется для охлаждения материнской платы, мезонинов или радиаторов СЖО.

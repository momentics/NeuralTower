## ХОМУТЫ

Каждое соединение шланга с фитингом = 1 хомут. Итого: 33 хомута + запас 10% = ~37 хомутов.

## ДЛИНА ШЛАНГА

Оценка по маршрутам:
- Помпа1→Помпа2: ~100 мм
- Помпа2→CPU WB: ~150 мм
- CPU WB→тройник: ~150 мм
- Тройник→GPU1: ~100 мм
- GPU1→GPU2: ~150 мм
- GPU2→объединение: ~100 мм
- Тройник→GPU3: ~100 мм
- GPU3→GPU4: ~150 мм
- GPU4→объединение: ~100 мм
- Объединение→Радиатор1: ~200 мм
- Радиатор1→Радиатор2: ~150 мм
- Радиатор2→Помпа1: ~200 мм
- Fillport (4×): ~800 мм (по 200 мм на каждый проход через палубу)
- Сливной кран: ~100 мм
- **Итого:** ~2550 мм + запас 30% = ~3315 мм

Текущий BOM: 3500 мм. Достаточно.

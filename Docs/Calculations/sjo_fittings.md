## ХОМУТЫ

Каждое соединение шланга с фитингом = 1 хомут. Итого: 37 хомутов + запас 10% = ~41 хомут.

## ДЛИНА ШЛАНГА

Оценка по маршрутам:
- Помпа1→Помпа2: ~100 мм
- Помпа2→CPU WB: ~150 мм
- CPU WB→тройник: ~150 мм
- Тройник→GPU1: ~100 мм
- GPU1→GPU2: ~150 мм
- GPU2→объединение: ~100 мм
- Тройник→GPU3: ~100 мм
- GPU3→GPU4: ~150 мм
- GPU4→объединение: ~100 мм
- Объединение→Радиатор1: ~200 мм
- Радиатор1→Радиатор2: ~150 мм
- Радиатор2→Помпа1: ~200 мм
- Fillport GPU (4×): ~800 мм (по 200 мм на каждый проход через палубу)
- Fillport CPU (2×): ~400 мм (по 200 мм на каждый проход через палубу)
- Сливной кран: ~100 мм
- **Итого:** ~3050 мм + запас 30% = ~3965 мм

Текущий BOM: 3500 мм. **НЕДОСТАТОЧНО! Нужно минимум 4000 мм.**

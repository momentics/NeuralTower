# Расчет длины SlimSAS SFF-8654 8i

Расчет выполнен для корпуса 500 x 300 x 524 мм с палубным поясом на высоте 260 мм. Физическая палуба является вкладным листом `458 x 258 мм`, установленным внутри пояса в области корпуса `X = 21-479 мм`, `Y = 21-279 мм`. Геометрия корпуса взята из [case_dimensions.md](./case_dimensions.md).

## 1. Вывод

Шлейфы SlimSAS не прокладываются в вычислительной камере. Мезонины установлены SlimSAS-разъёмами на нижнем краю платы (4× SFF-8654-8i вдоль кромки 236 мм). Кабели проходят через зазор 8 мм между лицевым и тыльным соплами каждого мезонина, спускаются в подпалубный кабельный коридор и возвращаются вверх к разъёмам PCIe-адаптеров.

Кабель не должен опускаться к дну КВД. Нижняя точка трассы находится сразу под палубой, в 15-миллиметровом коридоре между верхней сервисной поперечиной `Z = 245 мм` и герметичной палубой `Z = 260 мм`. Это сохраняет чистую зону вокруг плат и водоблоков, не перекрывает воздушные ножи и не заставляет кабель обходить радиаторы, блоки питания и помпы у основания корпуса. Рабочая трасса под палубой проходит в центральной полосе корпуса `X = 90-410 мм`, `Y = 25-115 мм`, что соответствует локальной зоне вкладного листа `Xd = 69-389 мм`, `Yd = 4-94 мм`. Отступ 4 мм от передней кромки палубы обеспечивает проход в зоне твёрдого металла.

Рабочий диапазон длины одного кабеля:

```text
L_work = 570-780 мм
```

Для закупки принимается стандартная длина 1000 мм, 8 шт. Длина 750 мм возможна только после макетной проверки конкретных адаптеров и ориентации разъемов.

## 2. Геометрия трассы

| Параметр | Значение |
| --- | ---: |
| Внутренняя ширина корпуса | 500 мм |
| Внутренняя глубина корпуса | 300 мм |
| Габарит вкладной палубы | 458 x 258 мм |
| Область вкладной палубы в координатах корпуса | X = 21-479 мм, Y = 21-279 мм |
| Габарит ASUS X99-E WS | 305 x 267 мм |
| Палубный пояс | Z = 260 мм |
| Плоскость материнской платы | около Z = 300 мм |
| Нижняя кромка мезонина | около Z = 300 мм |
| Рабочая плоскость подпалубного кабельного коридора | Z = 245-260 мм |
| Рабочая полоса кабельного коридора | X = 90-410 мм, Y = 25-115 мм |
| Рабочая полоса на листе палубы | Xd = 69-389 мм, Yd = 4-94 мм |
| Спуск от разъема до палубы | около 40 мм |
| Спуск от палубы до кабельного коридора | 0-15 мм |

Разъемы SFF-8654 на адаптерах PCIe остаются в верхнем отсеке. На мезонине все 4× SFF-8654 расположены вдоль нижнего края платы (236 мм), поэтому кабель от разъёма спускается вниз (~40 мм) и проходит через зазор 8 мм между соплами в подпалубное пространство. Свободная длина шлейфа не проходит через вычислительную камеру.

## 3. Маршрут кабеля

```text
PCIe/SlimSAS адаптер на ASUS X99-E WS (верхний отсек)
    |
    |  короткий выход от разъема, около 40 мм
    v
Зазор 8 мм между соплами мезонина, Z = 260-300 мм
    |
    |  проход через зазор между лицевым и тыльным соплами
    v
Подпалубный кабельный коридор, Z = 245-260 мм
    |
    |  горизонтальная укладка под палубой
    v
Возврат вверх через зазор 8 мм между соплами
    |
    |  подъем к разъему мезонина (нижний край платы, 236 мм)
    v
Мезонин SXM2, разъём SFF-8654-8i
```

Подпалубный коридор должен проходить над нижним оборудованием. Он не использует дно КВД как кабельный лоток и не заводит шлейфы между радиаторами, БП и помпами. Боковые PSU-отсеки занимают `X = 0-86 мм` и `X = 414-500 мм`, поэтому сервисные петли SlimSAS фиксируются только в центральной зоне.

## 4. Расчет длины

### 4.1. Горизонтальный участок

Горизонтальная часть зависит от конкретного слота PCIe, стороны мезонина и положения герметизированных окон палубы. Для скрытой трассы нужно учитывать не кратчайшую прямую между разъемами, а путь между парой проходов через палубу.

| Сценарий | Длина |
| --- | ---: |
| Ближний адаптер -> ближайший мезонин через подпалубный коридор | 290-340 мм |
| Дальний слот или обход стоек/сопел под палубой | 350-390 мм |

Для расчета принимается:

```text
L_horizontal = 290-390 мм
```

### 4.2. Вертикальные участки

Кабель дважды проходит через палубу: вниз от адаптера и вверх к мезонину. При этом он не опускается до отметки Z = 0 мм.

```text
L_vertical_adapter = 40 + 0-15 = 40-55 мм
L_vertical_mezzanine = 40 + 0-15 = 40-55 мм
L_vertical_total = 80-110 мм
```

### 4.3. Изгибы и монтажный запас

Для SFF-8654 нельзя закладывать резкий перегиб сразу после разъема и сразу после прохода через палубу. На четыре плавных перехода и фиксацию в подпалубном коридоре закладывается:

```text
L_bends = 120-160 мм
L_service = 80-120 мм
```

Сервисный запас хранится под палубой, закрепленным к кабельной планке или стяжечным площадкам. В вычислительной камере сервисная петля не допускается.

### 4.4. Итог

```text
L_min = 290 + 80 + 120 + 80 = 570 мм
L_max = 390 + 110 + 160 + 120 = 780 мм
```

Итоговая позиция для BOM:

```text
SlimSAS SFF-8654 8i: 1000 мм, 8 шт.
```

## 5. Требования к проходам через палубу

Кабели SlimSAS проходят через зазор 8 мм между лицевым и тыльным соплами каждого мезонина. Зазор формирует непрерывный коридор длиной 160 мм, через который 4 кабеля SlimSAS (SFF-8654-8i) спускаются в подпалубное пространство. Отдельные окна палубы для SlimSAS НЕ требуются.

Кабели питания (4× 8-pin) и шланги СЖО (2× EPDM 10/16) обходят сопла по бокам в свободных зонах ~38 мм с каждой стороны. Мезонины установлены зеркально: для Мезонина 1 питание слева и шланги справа, для Мезонина 2 — наоборот.

Зазор между соплами герметизируется вокруг кабелей вспененным уплотнителем или силиконовым герметиком для минимизации утечек давления из КВД.

## 6. Проверка при сборке

Перед закупкой нестандартной длины нужно проверить три вещи на макете:

1. Фактическую сторону выхода разъемов на PCIe/SlimSAS адаптерах.
2. Положение разъёмов SFF-8654 на мезонине (нижний край: 4× вдоль 236 мм).
3. Проходимость кабелей через зазор 8 мм между соплами (диаметр кабеля у корня 4-5 мм).

Если все разъемы развернуты в сторону ближайших зон сопел, 750 мм может хватить без запаса. Для проектной спецификации принимается 1000 мм, поскольку лишняя длина укладывается под палубой и не загромождает вычислительную камеру.

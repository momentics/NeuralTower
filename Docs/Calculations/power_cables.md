# Анализ кабелей блоков питания

## Маршрутизация кабелей

Кабели от БП маршрутизируются следующим образом:

1. От верха БП (Z=245 мм) поднимаются до палубного коридора (Z=245–260 мм)
2. Идут вверх через палубный коридор до материнской платы (Z=280–300 мм)
3. Для мезонинов кабели идут прямо вниз от верхней сервисной поперечины (Z=245 мм)

## Ведущий Chieftec Polaris Pro 1300W (Master)

*Обеспечивает питание вычислительного ядра системы, Мезонина 1 и транслирует сигнал запуска на Add2PSU. Пиковая нагрузка: ~953 Вт (материнская плата 50 Вт + CPU 160 Вт + RAM 128 Вт + NVMe 15 Вт + Мезонин 1 с двумя V100 PL 300W и платой-носителем 650 Вт = 2×300 + 50). Целевой длительный режим (инференс ~250W/GPU): ~803 Вт. IDLE (~60W/GPU): ~365 Вт.*

| Кабель | Кол-во | Назначение | Физическое примечание |
| :--- | :---: | :--- | :--- |
| **ATX 24-pin** | 1 | Системная материнская плата | Основной старт системы |
| **CPU 8-pin** | 2 | Системная материнская плата | Питание процессора Intel Xeon |
| **CPU 8-pin** | 2 | Мезонин 1 (GPU 0-1) | Питание логики первого мезонина |
| **PCIe 8-pin** | 2 | Мезонин 1 (Доп. питание) | Силовые цепи GPU 0 и GPU 1 |
| **PCIe 6-pin** | 1 | Материнская плата | Питание материнской платы (расположен почти в центре платы) |
| **Molex** | 1 | Сигнальный вход Add2PSU | Подача команды старта на ведомый БП |
| **SATA** | 1 | Системный SSD NVMe/SATA | Накопитель с операционной системой |

## Ведомый Chieftec Polaris Pro 1300W (Slave)

*Запускается через транзисторную плату Add2PSU HZ-0001 (Shenzhen Four One Technology Co., Ltd). Полностью обеспечивает работу Мезонина 2 и всей системы нестандартного жидкостного охлаждения. Пиковая нагрузка: ~735 Вт (Мезонин 2 с двумя V100 PL 300W и платой-носителем 650 Вт = 2×300 + 50 + две помпы D5 30 Вт + вентиляторы 45 Вт). Целевой длительный режим (инференс ~250W/GPU): ~560 Вт. IDLE (~60W/GPU): ~220 Вт.*

| Кабель | Кол-во | Назначение | Физическое примечание |
| :--- | :---: | :--- | :--- |
| **CPU 8-pin** | 2 | Мезонин 2 (GPU 2-3) | Питание логики второго мезонина |
| **PCIe 8-pin** | 2 | Мезонин 2 (Доп. питание) | Силовые цепи GPU 2 и GPU 3 |
| **SATA** | 2 | Помпы СВО D5 (2 шт.) | Силовое питание контура циркуляции жидкости |
| **SATA / Molex** | 1 | Вентиляторы радиаторов (6 шт.) | Питание распределительного PWM-хаба радиаторов |

| Тип физического кабеля | Ведущий БП (Master) | Ведомый БП (Slave) | Общее количество |
| :--- | ---: | ---: | ---: |
| **ATX 24-pin** | 1 | 0 | **1** |
| **CPU 8-pin (EPS)** | 4 | 2 | **6** |
| **PCIe 6+2-pin (GPU)** | 2 | 2 | **4** |
| **PCIe 6-pin (мат. плата)** | 1 | 0 | **1** |
| **SATA / Molex кабели** | 2 | 3 | **5** |

В заводской коробке одного БП Chieftec Polaris Pro 1300W поставляется 1 кабель CPU 8-pin и 1 кабель CPU 4+4-pin (итого 2 EPS-кабеля на БП). Для обеих коробок — 4 EPS-кабеля. Требуется 6: 2 на материнскую плату + 2 на Мезонин 1 (Master) + 2 на Мезонин 2 (Slave). **Недостаток: 2 EPS-кабеля.** Требуется докупка 2 дополнительных модульных EPS 8-pin кабелей, совместимых с Chieftec Polaris Pro 1300W.

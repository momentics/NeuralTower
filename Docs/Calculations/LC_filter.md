# LC-фильтр для сигнала PWR_OK в схеме двойного питания

При использовании схемы синхронизации второго блока питания через Add2PSU возникает необходимость в фильтрации сигнала PWR_OK. Этот сигнал от первого блока питания передаётся на вход управления второго, но содержит переходные процессы и шумы, которые могут привести к некорректному включению обоих блоков одновременно или к сбоям в работе системы.

Внедрение LC-фильтра на сигнал PWR_OK позволяет обеспечить согласованный запуск обоих блоков питания, исключить сбои работы системы и повысить надёжность эксплуатации сервера с четырьмя графическими процессорами NVIDIA Tesla V100 SXM2.

## Принцип работы Add2PSU

Add2PSU представляет собой простейший сигнальный переключатель. При появлении напряжения на выводе PWR_OK первого блока питания схема замыкает контакт PS_ON на втором блоке, заставляя его включиться. Однако сигнал PWR_OK не является идеальным:

- Содержит дребезг при включении
- Включает шумы от переходных процессов в диапазоне 100-500 Гц
- Может иметь скачки напряжения при перегрузках

## Почему фильтрация необходима для V100

Графические процессоры NVIDIA Tesla V100 SXM2 характеризуются высоким стартовым током. При включении каждый процессор требует мгновенный ток до 150 ампер при напряжении 12 вольт. В нашей конфигурации четыре таких процессора на двух мезонинах создают суммарную нагрузку порядка 1,2 кВт.

Без фильтрации сигнала PWR_OK возможны следующие проблемы:

- Нестабильный запуск второго блока питания
- Скачки напряжения на линии +12V
- Ошибки Xid 79 (проблемы шины PCIe) и Xid 48 (нарушения питания)

## Расчёт тока в цепи фильтра

Сигнал PWR_OK выдаёт напряжение +5VSB с первого блока питания. При включении второго блока через Add2PSU ток через цепь управления составляет:

```
Ток через PS_ON (типичный для ATX) = 2–5 мА
Запас по току = 5–10 раз
Требуемый ток контура = 20–50 мА
```

Ток в цепи PWR_OK не превышает 50 мА, следовательно, LC-фильтр работает в режиме сигнального уровня, а не силового.

## Расчёт параметров LC-фильтра

### Выбор частоты среза

Для эффективной фильтрации шумов в диапазоне 100-500 Гц необходимо установить частоту среза ниже нижней границы этого диапазона. При выборе компонентов L = 1000 мГн и C = 1000 мФ частота среза составляет:

```
fc = 1 / (2π√(1000 × 10⁻³ × 10⁻³)) ≈ 159 Гц
```

Этого достаточно для подавления шумов выше 100 Гц.

### Формула расчёта

Для LC-фильтра второго порядка частота среза определяется формулой:

```
fc = 1 / (2π√LC)
```

где:
- fc — частота среза в герцах
- L — индуктивность в генри
- C — ёмкость в фарадах

### Подбор компонентов

Выбираем ёмкость конденсатора C = 1000 мФ. Это стандартное значение, которое легко приобрести. Подставляя в формулу для расчёта индуктивности при частоте среза 150 Гц:

```
L = 1 / (4π² × 150² × 10⁻³) ≈ 1126 мГн
```

Округляем до стандартного значения **L = 1000 мГн**.

## Требования к компонентам фильтра

### Индуктивность

Необходима ферритовая катушка с такими параметрами:

- Номинальная индуктивность: 1000 мГн
- Ток сатурации: не менее 10 А
- Сопротивление провода: не выше 50 мОм
- Рабочая температура: 40…85 °C

#### Толщина провода для ручной обмотки

При ручном изготовлении индуктивности на сердечнике диаметром 10 мм потребуется 50-100 витков. Сечение провода выбирается с учётом тока 50 мА:

```
Сечение провода: 0,5–0,75 мм²
Толщина провода: AWG-24…AWG-22
Рекомендуемый провод: ПВЗ-ЛСГ с сечением 0,75 мм² (d = 1,06 мм)
```

Падение напряжения на проводе при токе 50 мА:

```
ΔU = I × Rпр = 0,05 А × 0,05 Ом = 2,5 мВ
```

Это значительно ниже допустимых 50 мВ при напряжении 5 В.

### Конденсатор

Для ручного изготовления подходит электролитический конденсатор с выводными контактами.

#### Напряжение конденсатора

Конденсатор подключается к линии PWR_OK с напряжением +5VSB. Берём запас по напряжению:

```
Рабочее напряжение: 5,5 В (с запасом до 7 В)
Необходимое напряжение конденсатора: не менее 10 В
Рекомендуемое: 16 В (стандартное значение)
```

#### Параметры конденсатора

- Ёмкость: 1000 мФ
- Напряжение: 16 В
- ESR (эквивалентное серийное сопротивление): не выше 50 мОм
- Температурный диапазон: -40...+105 °C
- Стандартный диаметр выводов: 5 мм, высота: 11 мм

## Реализация схемы

LC-фильтр устанавливается последовательно на сигнальном проводе PWR_OK:

```
Пин 8 разъёма ATX (PWR_OK) → [1000 мГн] → вывод Add2PSU
                                       ↓
                                  [1000 мФ] → земля (любой GND)
```

При сборке необходимо соблюдать следующие правила:

1. Конденсатор устанавливается как можно ближе к входу Add2PSU для минимизации индуктивности проводов.
2. Индуктивность должна находиться в магнитном экранировании, если планируется размещение вблизи других компонентов.
3. Все соединения желательно выполнять спаиванием для надёжности.

## Проверка работы фильтра

Для проверки качества фильтрации необходимо измерить сигнал PWR_OK осциллографом:

- Перед включением фильтра: наблюдаются дребезг и нестабильные фронты
- После включения фильтра: фронты должны быть менее 5 мс, амплитуда падения напряжения не должна превышать 0,5 В

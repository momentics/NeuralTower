# Статус проекта и план проверки

Документ фиксирует текущую степень подтверждения решений. Доказательство концепции (PoC) успешно завершено: стенд из двух GPU V100 SXM2 32 ГБ на одном мезонине собран, протестирован и показал работоспособность всей цепочки PCIe-SlimSAS-GPU с инференсом модели Qwen3.6-27B на скорости 32,69 токена в секунду. Полноценная сборка на четырёх GPU с жидкостным охлаждением и двумя блоками питания находится в стадии подготовки. Тепловые, акустические и часть электрических выводов для полной конфигурации считаются расчётными до сборки финального узла.

**Критическое замечание по мощности:** NVIDIA Tesla V100 SXM2 32GB имеет PL (Power Limit) 300W. Все расчёты мощности и охлаждения выполнены с учётом этого ограничения. Водоблок Speedier XF-001-CO (300W TDP) полностью соответствует мощности GPU.

**Ключевые выводы пересчёта охлаждения (2026-07-17):**
- Пиковая нагрузка на СЖО: **1290W** (4×280W GPU + 140W CPU + 30W помпы). Расход 5.2 л/мин, ΔT теплоносителя 4.38 °C.
- Пиковая нагрузка на воздух: **380W**. Расход 0.0566 м³/с.
- Температура КВД: **43,9 °C** (пик), **40,9 °C** (инференс). Воздух нагревается на радиаторах СЖО на 18,9 °C.
- Температура выхлопа: **49,5 °C** (пик), **45,0 °C** (инференс).
- Запас по мезонинам: **+116,1 Вт (290%)** при пике.
- Запас по VRM MB: **минимальный** (ёмкость ≈ нагрузка при пике).
- Запас по CPU бэкплейту: **+14,6 °C** при инференсе, **+6,8 °C** при TDP.
- Температуры GPU: **49,5–54,5 °C** (пик), **43,8–49,8 °C** (инференс).

## Что уже готово

- Выбрана платформа: ASUS X99-E WS, Xeon E5-2687W v4 (12 ядер, 24 потока, TDP 160 Вт), четыре Tesla V100 SXM2 32 ГБ, две платы-носителя SXM2 и 256 ГБ DDR4 ECC.
- Определена базовая механика: профиль 20 x 20 мм, нижняя камера давления 260 мм, вкладная палуба 458 x 258 мм на внутреннем опорном уголке, верхний вычислительный отсек 264 мм.
- Подготовлены расчетные записки по аэродинамике, гидравлике, объему теплоносителя, SlimSAS-трассам и пропускной способности PCIe/NVLink.
- Полностью стандартизирована схема питания мезонинов: исключены нестандартные переходники PCIe->CPU в пользу прямого кабельного подключения Chieftec Polaris Pro 1300W CPU/EPS.
- Смонтированы только GPU 8-pin и CPU 8-pin входы мезонинов (без ATX 24-pin).
- Определена схема синхронизации запуска двух БП через Add2PSU HZ-0001 с MOSFET-коммутацией без дребезга.
- Реализованы процедуры проверки состояния GPU при запуске и фоновый мониторинг GPU: проверка наличия всех 4 GPU перед запуском vLLM/SGLang и непрерывный мониторинг с автоматическим плавным завершением рабочих контейнеров при потере любого GPU.
- Описан программный стек для Volta: Gentoo Linux, CUDA 12.8, Python 3.12, vLLM 0.18.x или SGLang.
- Подготовлен контейнер диагностики V100 на базе NVIDIA DCGM.

## Что требует физической проверки

- Фактическая температура VRM под длительной нагрузкой.
- Температура HBM2 при многочасовом инференсе и дообучении.
- Реальная скорость воздушных потоков после сборки корпуса.
- Шум системы в настольном режиме.
- Устойчивость палубы к утечкам воздуха.
- Герметичность изолированных PSU-отсеков относительно КВД.
- Стабильность двух помп в выбранной гидравлической схеме.
- Корректная работа всех четырех V100 через PLX-коммутаторы.
- Стабильность GPUDirect P2P между мезонинами.
- Фактическая производительность на моделях класса 70B.
- Польза vLLM swap на реальных длинных контекстах.
- Поведение системы при отказе одной помпы или одного вентилятора.

## Минимальный план первичной проверки

1. Проверить питание без установленных GPU.
2. Проверить совместный старт двух БП через Add2PSU.
3. Проверить общую землю между корпусами БП и рамой.
4. Проверить, что вентиляторы Chieftec Polaris Pro 1300W забирают воздух только через боковые фильтры и не подсасывают воздух из КВД.
5. Проверить наружный доступ к выключателям и IEC-разъёмам Chieftec Polaris Pro 1300W.
6. Проверить герметичность уплотнения КВД и изоляцию воздушного потока БП.
7. Провести тест герметичности контура СЖО под давлением.
8. Проверить работоспособность и производительность помп D5.

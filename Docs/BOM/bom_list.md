# Спецификация компонентов и материалов системы NeuralTower

Для реализации настольного вычислительного узла мощностью 1.4 кВт выбран перечень материалов, обеспечивающих жесткость конструкции и стабильный теплообмен. Все позиции подобраны с учетом интеграции профессионального серверного оборудования в кастомный алюминиевый каркас.

## 1. Силовая рама и конструкционные элементы

Основу скелета NeuralTower составляет алюминиевый профиль сечением 20 x 20 мм с пазом 6 мм. Размеры каркаса получены из компоновочного расчета, приведенного в [../Calculations/case_dimensions.md](../Calculations/case_dimensions.md). Для сборки требуются четыре вертикальные стойки по 590 мм, шесть профилей ширины по 500 мм для нижнего, палубного и верхнего поясов, шесть профилей глубины по 300 мм для этих же поясов, две боковые сервисные рельсы по 300 мм и две сервисные поперечины по 500 мм. Внутренний объем корпуса составляет 500 x 300 x 590 мм, внешний размер рамы - 540 x 340 x 590 мм. Палубный пояс устанавливается на высоте 260 мм от нижнего края стоек, а вкладная палуба АМг3 `458 x 258 x 3 мм` утапливается внутрь этого пояса.

Внутри вычислительного отсека устанавливаются четыре вертикальных стапеля длиной по 300 мм, предназначенные для жесткой фиксации тяжелых мезонинов. В нижнем ярусе сначала монтируются две боковые сервисные рельсы по 300 мм на `Z = 95 мм`, затем две сервисные поперечины по 500 мм: нижняя на `Y = 115 мм`, `Z = 95 мм`, верхняя на `Y = 115 мм`, `Z = 245 мм`. Они формируют переднюю грань боковых PSU-отсеков, опоры помп и нижнюю границу подпалубного коридора SlimSAS. Верхняя сервисная поперечина крепится снизу к левому и правому 300-мм профилям глубины палубного пояса: двухсторонний уголок 2020 прижимается одной полкой к вертикальной боковой грани профиля глубины, второй - к нижней грани поперечины; оба соединения затягиваются через Т-гайки M5. Габаритные углы рамы собираются на 3-сторонних T-образных угловых кронштейнах 2020, остальные узлы - на двухсторонних угловых кронштейнах 2020. Для силовой сборки профиля используются только винты M5 ISO 7380 и пазовые Т-гайки M5; M4 оставляется для палубного листа, помп, кожухов и прочего навесного оборудования.

Расчет крепежа рамы выполнен по схеме из [../../CAD/Frame/frame_assembly.md](../../CAD/Frame/frame_assembly.md). Нижний и верхний пояса образуют восемь внешних габаритных углов, поэтому для них требуется 8 трехсторонних кронштейнов. Палубный пояс находится на высоте 260 мм на уже установленных стойках и крепится двухсторонними кронштейнами: 4 угла x 2 примыкающих профиля = 8 шт. Внутренние стапели, боковые рельсы и сервисные поперечины считаются отдельно: 4 стапеля x 4 кронштейна + 2 боковые рельсы x 2 кронштейна + 2 поперечины x 4 кронштейна = 28 шт. Итого двухсторонних кронштейнов: 8 + 28 = 36 шт.

Расчет винтов и Т-гаек: трехсторонние кронштейны требуют `8 x 3 = 24` точки M5, двухсторонние кронштейны требуют `36 x 2 = 72` точки M5. Силовые кронштейны рамы дают 96 комплектов M5. Опорный уголок палубы крепится к профилю палубного пояса еще 20 точками M5. Для закупки принимается 120 винтов `M5 x 8 мм` и 140 Т-гаек M5 с запасом; 40 винтов `M5 x 10 мм` закупаются как альтернативная длина для толстых полок кронштейнов или мест с шайбой и не увеличивают расчетное количество Т-гаек. Для листа палубы сохраняется отдельный крепеж `M4 x 12 мм` с шайбами и самоконтрящимися гайками, 32 комплекта.

## 2. Компоненты гидравлического контура

Система жидкостного охлаждения спроектирована под использование шланга из синтетического каучука EPDM с внутренним диаметром 10 мм. Циркуляцию обеспечивают два комбо-устройства Bykski B-UL-D5-X-V4, каждое из которых включает в себя помпу стандарта D5, резервуар 60 мм и защитный алюминиевый кожух. Теплосъем осуществляется парой медных радиаторов Bykski CR-RD360RC-TK60-V2 габаритом 395.5 x 122 x 60 мм, установленных горизонтально в основании корпуса длинной стороной вдоль ширины рамы. Радиаторы являются воздухопроницаемой частью герметичного дна КВД: снизу поток проходит через накладные магнитные фильтры и вентиляторы, затем через окна нижнего поддона и оребрение радиаторов.

Комплект теплосъемников включает водоблок для процессора LGA 2011-3 и четыре полнопоточных водоблока для ускорителей Tesla V100. Обдув радиаторов реализован шестью вентиляторами Thermaltake TOUGHFAN 12, нагнетающими воздух через нижние магнитные фильтры в радиаторы и далее в КВД. Для сборки магистралей требуется 20 компрессионных фитингов стандарта 10/16 мм, 10 поворотных адаптеров на 90°, 4 адаптера на 45° и 3 Т-образных разветвителя. Герметичный переход шлангов через алюминиевую перегородку обеспечивают четыре проходных фитинга типа Fillport.

## 3. Интерфейсы данных и подсистема питания

Энергоснабжение системы разделено между двумя модульными блоками Corsair HX1000 Platinum, работающими в паре через синхронизатор Add2PSU. Блоки питания устанавливаются в изолированных боковых отсеках нижнего яруса: вентиляторная сторона получает воздух через боковые фильтры, а IEC-разъемы, персональные выключатели и выхлопные решетки выходят на заднюю панель. Передача данных от материнской платы ASUS X99-E WS к ускорителям выполняется восемью экранированными шлейфами SlimSAS SFF-8654 8i расчетной длиной 1000 мм. Основная длина шлейфов укладывается в подпалубном кабельном коридоре, поэтому кабели не проходят через вычислительную камеру. Для подключения кабелей используются четыре адаптера-разветвителя с PCIe x16 на два порта SlimSAS, поддерживающие режим разделения линий шины. Питание логики мезонинов реализовано через кастомные переходники с PCIe 8-pin на CPU 8-pin, изготовленные из медного провода сечением 0.82 мм².

## 4. Материалы корпуса и герметизации

Разделение температурных зон выполнено с помощью вкладной алюминиевой палубы толщиной 3 мм, в которой прорезаны прецизионные отверстия для воздушных ножей. Палуба опирается на внутренний алюминиевый уголок `20 x 20 x 2 мм`: уголок крепится к профилю винтами M5, а лист палубы притягивается к уголку винтами M4. Герметичное дно КВД формирует отдельный алюминиевый поддон `500 x 300 x 3 мм` с двумя окнами `380 x 106 мм` под радиаторы. Радиаторы прижимаются к поддону через EPDM-контур, а сэндвич вентилятор-поддон-уплотнитель-радиатор стягивается винтами UNC 6-32. Герметичность стыков палубы, нижнего поддона и рамок изолированных PSU-отсеков обеспечивается мягким самоклеящимся EPDM-уплотнителем толщиной 4 мм; углы уплотнителя стыкуются в ус и промазываются автомобильным силиконовым формирователем прокладок. Внешний облик и защиту узла формируют боковые акриловые панели толщиной 5 мм с магнитными нейлоновыми фильтрами, а также перфорированная верхняя крышка, обеспечивающая свободный выход нагретого воздуха из системы.

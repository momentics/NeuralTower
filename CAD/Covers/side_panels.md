# Спецификация боковых панелей NeuralTower

## 1. Архитектура: двухзонные панели

Боковые панели разделены по высоте на две зоны с разными материалами:

| Зона | Высота (Z) | Материал | Назначение |
| --- | --- | --- | --- |
| Нижняя | Z = 0-260 мм | Анодированный алюминий, 2 мм, НЕПРОЗРАЧНЫЙ | Скрывает КВД (БП, помпы, кабели, трубки) |
| Верхняя | Z = 260-524 мм | Прозрачный акрил, 5 мм, ПРОЗРАЧНЫЙ | Визуальный доступ к вычислительному отсеку |

Разделение на уровне палубного пояса Z = 260 мм обеспечивает изоляцию КВД от визуального контакта при сохранении прозрачности вычислительного отсека.

## 2. Геометрия рамы

| № | Профиль | Y (мм) | Z (мм) |

| 2 | Передний (Y=0) | 0 | 100 |
| 3 | Передний (Y=0) | 0 | 200 |
| 4 | Передний (Y=0) | 0 | 260 |
| 5 | Задний (Y=340) | 340 | 0 |
| 6 | Задний (Y=340) | 340 | 260 |
| 7 | Верхний (Z=260) | 85 | 260 |
| 8 | Верхний (Z=260) | 170 | 260 |
| 9 | Верхний (Z=260) | 255 | 260 |

Итого: **10 точек крепления** на левую нижнюю панель.

## 5. Крепление панелей к раме

### 5.1. Принцип крепления

```
  Внешняя сторона                    Внутренняя сторона
  ════════════════════════════════════════════════════════

  Нижняя панель (алюминий 2 мм):
  ┌─────────────┐    ┌──────────────────────────────────┐
  │  Алюминий   │◄───│ Профиль 20x20                    │
  │  2 мм       │    │  ┌────────────────────────────┐  │
  │    ⌀4.5     │    │  │  T-паз 6 мм                │  │
  │             │    │  │  ═══ Т-гайка M4 ═══        │  │
  │             │    │  └────────────────────────────┘  │
  └─────────────┘    └──────────────────────────────────┘
         │                    │
         └─── Винт M4 x 8 ───┘
         2 мм алюминий + 6 мм резьбы в Т-гайке

  Верхняя панель (акрил 5 мм):
  ┌─────────────┐    ┌──────────────────────────────────┐
  │  Акрил 5 мм │◄───│ Профиль 20x20                    │
  │             │    │  ┌────────────────────────────┐  │
  │    ⌀4.5     │    │  │  T-паз 6 мм                │  │
  │             │    │  │  ═══ Т-гайка M4 ═══        │  │
  │             │    │  └────────────────────────────┘  │
  └─────────────┘    └──────────────────────────────────┘
         │                    │
         └─── Винт M4 x 10 ──┘
         5 мм акрил + 5 мм резьбы в Т-гайке
```

### 5.2. Расход крепежа

| Компонент | Нижние панели (2 шт.) | Верхние панели (2 шт.) | Всего |
| --- | ---: | ---: | ---: |
| Винт M4 x 8 ISO 7380 | 10 × 2 = 20 | — | 20 |
| Винт M4 x 10 ISO 7380 | — | 8 × 2 = 16 | 16 |
| Т-гайка M4, паз 6 | 10 × 2 = 20 | 8 × 2 = 16 | 36 |

### 5.3. Порядок монтажа

1. Установить Т-гайки M4 в T-пазы профилей по позициям крепления.
2. Установить EPDM-рамки на окна PSU (до монтажа панелей).
3. Установить нижнюю панель, совместить отверстия с Т-гайками.
4. Затянуть винты M4 x 8 равномерно от центра к краям.
5. Установить верхнюю панель, совместить отверстия с Т-гайками.
6. Затянуть винты M4 x 10 равномерно от центра к краям.
7. Установить магнитные фильтры.

## 6. EPDM-рамки для окон PSU

### 6.1. Геометрия

| Параметр | Значение |
| --- | --- |
| Внутренний размер (по окну) | 150 x 140 мм |
| Ширина рамки | 10 мм |
| Внешний размер | 170 x 160 мм |
| Толщина EPDM | 4 мм |
| Материал | Вспененный EPDM, самоклеящийся |

EPDM-рамка укладывается на внутреннюю сторону алюминиевой панели вокруг окна. Внешний край прижимается панелью к профилю рамы, внутренний — к изоляционной стенке PSU-отсека.

### 6.2. Расчет длины EPDM-ленты

Периметр рамки: 2 × (170 + 160) = 660 мм на рамку.
Всего на 2 рамки: **1320 мм** EPDM-ленты 4 мм.

### 6.3. Установка

1. Нарезать EPDM-ленту 4 мм шириной 10 мм по периметру.
2. Углы стыковать в ус под 45°.
3. Приклеить на внутреннюю сторону алюминиевой панели по контуру окна.
4. Проверить герметичность прижима.

## 7. Фильтры и магнитный крепеж

### 7.1. Фильтр

| Параметр | Значение |
| --- | --- |
| Размер | 150 x 140 мм |
| Материал | Нейлон, съемный |
| Крепление | Магниты |
| Количество | 2 шт. (левый + правый) |

### 7.2. Магниты

| Параметр | Значение |
| --- | --- |
| Тип | N52, неодимовые |
| Размер | ⌀6 x 2 мм |
| Усилие удержания | ~0.5 Н на магнит |
| Количество | 4 шт. на окно, 8 шт. всего |

Магниты вклеиваются во внутреннюю сторону алюминиевой панели по периметру окна PSU. Фильтр имеет стальную вставку для магнитного удержания.

**Позиции магнитов (координаты центра):**

| Магнит | Y (мм) | Z (мм) |
| --- | ---: | ---: |
| 1 (верх-перед) | 140 | 115 |
| 2 (верх-зад) | 260 | 115 |
| 3 (низ-перед) | 140 | 225 |
| 4 (низ-зад) | 260 | 225 |

Суммарное усилие удержания: 4 × 0.5 = 2.0 Н (достаточно для фильтра ~10 г).

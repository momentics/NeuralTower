# Спецификация сопла охлаждения мезонина V100

## 1. Назначение и количество

Каждый мезонин (2 шт) обдувается двумя соплами: лицевым (обдув текстолита с использованием эффекта Коанда) и тыльным (обдув корпуса водоблока и пластины-спредера VRM). Итого **4 сопла** на палубу. Все 4 сопла идентичны по геометрии, различается только ориентация при монтаже.

Сопло устанавливается на палубе в зазоре 40 мм между палубой и нижней кромкой мезонина. Конвергентный канал сужает поток от входной прорези 160×10 мм до выходной щели 156×3.0 мм. Выходная щель наклонена на 10.54° от горизонтали (номинально 12°), направляя воздушный нож на нижнюю кромку вертикально установленного мезонина.

## 4. Расположение на палубе

### 4.1. Схема размещения

  │  ┌──────────┐              ┌────────────────────────────┐    │
  │  │SlimSAS   │              │  Мезонин 170 мм (ось Z)    │    │
  │  │ разъёмы  │              │  (плоскость платы)         │    │
  │  └──────────┘              └────────────────────────────┘    │
  │                      ▲                                       │
  │                      │ 32 мм                                 │
  │  ┌────────────────────────────────────────────────────┐      │
  │  │            СОПЛО ЛИЦЕВОЕ (32 мм)                   │      │
  │  │            ← 160 мм →                              │      │

## 6. Проход кабелей и шлангов через зону сопел

### 6.1. Расположение разъёмов на мезонине

Сопла 160 мм перекрывают центральную зону мезонина (GPU + VRM). Зона сопла по оси X занимает ~38-198 мм от левого края мезонина (236 мм). Крайние ~38 мм с каждой стороны остаются свободными от сопел.

Разъёмы на мезонине (подтверждено фотографиями):
- **Нижний край мезонина (236 мм):** 4× SFF-8654-8i SlimSAS, расположены вдоль всей нижней кромки
- **Левый край мезонина (170 мм):** 2× CPU 8-pin + 2× GPU 8-pin питание, stacked вертикально
- **Левый край (над питанием):** 1× ATX 24-pin (не подключён в NeuralTower)

Зона SlimSAS-разъёмов (нижний край) частично перекрывается проекцией сопел. Кабели от SlimSAS проходят через зазор 8 мм между соплами. Кабели питания и шланги СЖО обходят сопла по бокам.

### 6.2. Что спускается вниз от каждого мезонина

| Элемент | Кол-во | Ширина/диаметр | Зона прохода |
| --- | ---: | ---: | --- |
| SlimSAS SFF-8654-8i | 4 кабеля | ~4 мм у корня | Зазор 8 мм между соплами |
| Питание CPU/GPU 8-pin | 4 кабеля | ~8-10 мм пучок | Мез1: слева, Мез2: справа (зеркально) |
| Шланги СЖО EPDM 10/16 | 2 шланга | 16 мм НД | Мез1: справа, Мез2: слева (зеркально) |

**Итого ширина:** ~84 мм. Мезонин 236 мм. Сопла 160 мм по центру. Свободные зоны: ~38 мм слева + ~38 мм справа.

**Важно:** Мезонины установлены зеркально. Для Мезонина 1 питание слева, шланги справа. Для Мезонина 2 — наоборот: питание справа, шланги слева.

### 6.3. Зазор 8 мм между соплами — ТОЛЬКО SlimSAS

| Параметр | Значение |
| --- | --- |
| Высота зазора | 8 мм |
| Длина зазора (ось X) | 160 мм (полная длина сопел) |
| Назначение | Проход SlimSAS-кабелей в подпалубное пространство |
| **НЕ проходят через зазор** | Шланги СЖО (16 мм > 8 мм) и кабели питания (8-10 мм > 8 мм) |

### 6.4. Трассировка SlimSAS-кабелей (через зазор 8 мм)

Все 4× SFF-8654-8i расположены вдоль нижнего края мезонина (236 мм). Кабели свисают вниз от разъёмов и проходят через зазор 8 мм между лицевым и тыльным соплами. Кабели укладываются вдоль зазора и спускаются вниз.

| Параметр | Значение |
| --- | ---: |
| Диаметр кабеля у корня | 4-5 мм |
| Минимальный радиус изгиба | 15-20 мм |
| Кабелей на мезонин | 4 |
| Проход через зазор | Все 4 кабеля через зазор 8 мм |

### 6.5. Трассировка кабелей питания (зеркально, ВНЕ сопел)

4 кабеля питания (2× CPU 8-pin EPS + 2× GPU 8-pin PCIe) отходят от края мезонина с разъёмами питания. Из-за зеркальной установки мезонинов:

- **Мезонин 1:** кабели слева, спускаются в левой свободной зоне (~38 мм).
- **Мезонин 2:** кабели справа (зеркально), спускаются в правой свободной зоне (~38 мм).

| Параметр | Значение |
| --- | ---: |
| Кабелей питания на мезонин | 4 |
| Ширина пучка одного кабеля | 8-10 мм |
| Общая ширина 4 кабелей | ~36 мм |
| Свободная зона слева от сопел | ~38 мм |
| Запас | ~2 мм (КРИТИЧЕСКИ, требует точной укладки) |

### 6.6. Шланги СЖО от водоблоков (зеркально, ВНЕ сопел)

Водоблоки Speedier XF-001-CO подключены последовательно: вход → GPU1 → GPU2 → выход. От каждого мезонина вниз уходит 2 шланга EPDM 10/16 мм (1 вход + 1 выход). Межблочный шланг (GPU1→GPU2) остаётся в зоне мезонина и не спускается вниз.

Из-за зеркальной установки мезонинов шланги спускаются с разных сторон:

- **Мезонин 1:** шланги справа, спускаются в правой свободной зоне (~38 мм).
- **Мезонин 2:** шланги слева (зеркально), спускаются в левой свободной зоне (~38 мм).

В палубе шланги проходят через проходные фитинги Fillport (⌀20 мм).

| Параметр | Значение |
| --- | ---: |
| Шлангов на мезонин (вниз) | 2 (1 вход + 1 выход) |
| Межблочный шланг | 1 (остается в зоне мезонина) |
| Наружный диаметр шланга | 16 мм (EPDM 10/16) |
| Фитинг | G1/4 compression |
| Проход через палубу | Fillport ⌀20 мм |
| Общая ширина 2 шлангов | 32 мм |
| Свободная зона справа от сопел | ~38 мм |
| Запас | ~6 мм |

### 6.7. Герметизация

**Зазор 8 мм между соплами (SlimSAS):**
Зазор не является полностью герметичным — через него проходят 4 SlimSAS-кабеля. Для минимизации утечек давления из КВД:
- Кабели укладываются плотно к стенкам сопел
- Оставшееся пространство между кабелями и стенками сопел заполняется вспененным уплотнителем или силиконовым герметиком

**Шланги СЖО:**
Шланги герметичны сами по себе (проходят через Fillport в палубе). Дополнительная герметизация не требуется.

**Кабели питания:**
Проходят вне зоны сопел, герметизация не требуется.

### 6.8. Последовательность монтажа

1. Мезонины устанавливаются на боковые направляющие на высоте 40 мм от палубы.
2. Кабели питания (4× 8-pin) подключаются к краю мезонина с разъёмами питания. Мезонин 1: слева, Мезонин 2: справа (зеркально).
3. Шланги СЖО подключаются к водоблокам на мезонине. Мезонин 1: справа, Мезонин 2: слева (зеркально).
4. SlimSAS-кабели (4× SFF-8654) подключаются к нижнему краю мезонина.
5. SlimSAS-кабели укладываются в зазор 8 мм между лицевым и тыльным соплами.
6. Палуба с соплами опускается сверху. Сопла охватывают SlimSAS-кабели с обеих сторон.
7. Кабели питания и шланги СЖО проходят по бокам от сопел (свободные зоны ~38 мм).
8. Шланги СЖО проходят через Fillport-отверстия в палубе.
9. Зазор между соплами герметизируется вокруг SlimSAS-кабелей.
10. Сопла прикручиваются к палубе винтами M3 × 8 мм.

### 7.3. Рабочая точка системы

Сопротивление сети:
```
ΔP = ξ × (ρ/2) × (Q/S_total)²
ΔP = 1.45 × 0.6 × (Q/0.01155)²
ΔP = 0.87 × (Q/0.01155)²
ΔP = 6521.6 × Q²
```

Уравнение рабочей точки:
```
23.63 × [1 − (Q/0.1652)²] = 6521.6 × Q²
23.63 = Q² × (6521.6 + 23.63/0.1652²)
23.63 = Q² × (6521.6 + 865.9)
23.63 = Q² × 7387.5
Q = √(23.63/7387.5) = 0.0566 м³/с
```

| **Статическое давление в КВД** | **P_КВД = 20.9 Па** |

### 7.8. Коэффициент теплоотдачи (корреляции для щелевой струи)

**Важно:** Для расчёта теплоотдачи от щелевой струи (slot jet), импиджирующей на вертикальную поверхность, используются специализированные корреляции, а не формула Dittus-Boelter (применимая к течению в трубах).

#### 7.8.1. Зона импиджмента (stagnation zone, x = 0–15 мм)

Струя выходит из щели под углом 10.54° (номинально 12°) и попадает на нижнюю кромку мезонина. В зоне импиджмента коэффициент теплоотдачи максимален.

Корреляция для slot jet impingement:
```
Nu_stag = 0.62 × Re^0.5 × Pr^0.36 × (W/h)^0.15

Re = 6222,  Pr = 0.71,  W/h = 156/3 = 52

Re^0.5 = √6222 = 78.88
Pr^0.36 = 0.71^0.36 = 0.882
(W/h)^0.15 = 52^0.15 = 1.607

Nu_stag = 0.62 × 78.88 × 0.882 × 1.607 = 69.2

α_stag = Nu_stag × λ / Dh = 69.2 × 0.0262 / 0.006 = 302 Вт/(м²·К)
```

#### 7.8.2. Зона пристеночной струи (wall jet, x = 15–150 мм)

После импиджмента струя распространяется вдоль вертикальной поверхности мезонина. Коэффициент теплоотдачи убывает с расстоянием.

Корреляция для wall jet от щелевого сопла:
```
Nu_x = 0.05 × Re^0.67 × (x/h)^(-0.06)

Re^0.67 = 6222^0.67 = 495.0
Константа: 0.05 × 495.0 = 24.75

При x = 10 мм:  Nu = 24.75 × (10/3)^(-0.06) = 24.75 × 0.913 = 22.6
При x = 50 мм:  Nu = 24.75 × (50/3)^(-0.06) = 24.75 × 0.823 = 20.4
При x = 100 мм: Nu = 24.75 × (100/3)^(-0.06) = 24.75 × 0.767 = 19.0
При x = 150 мм: Nu = 24.75 × (150/3)^(-0.06) = 24.75 × 0.740 = 18.3
```

Среднее Nu_wall (интеграл от x=5 до x=150 мм):
```
∫(x/h)^(-0.06) dx от 5 до 150 = h × [(x/h)^0.94 / 0.94] от 5 до 150
= 0.003 × (50^0.94 − 1.667^0.94) / 0.94
= 0.003 × (40.31 − 1.613) / 0.94
= 0.003 × 41.167 = 0.1235

Среднее (x/h)^(-0.06) = 0.1235 / 0.145 = 0.852
Nu_wall_avg = 24.75 × 0.852 = 21.1

α_wall_avg = 21.1 × 0.0262 / 0.006 = 92.1 Вт/(м²·К)
```

#### 7.8.3. Средний коэффициент теплоотдачи

```
α_avg_base = (15 × 302 + 145 × 92.1) / 160
           = (4530 + 13355) / 160
           = 17885 / 160
           = 111.8 Вт/(м²·К)

Лицевая сторона (эффект Коанда, k = 1.15):
  α_front = 111.8 × 1.15 = 128.6 Вт/(м²·К)

Тыльная сторона (шероховатость водоблока, k = 1.10, с учётом рециркуляции за водоблоками):
  α_back = 104.1 Вт/(м²·К)

  Детализация зон тыльной стороны:
  - x = 0-15 мм: импиджмент, α = 302 Вт/(м²·К), площадь = 2,340 мм²
  - x = 15-85 мм: wall jet до водоблока, α = 92, площадь = 10,920 мм²
  - x = 85-95 мм: отрыв у водоблока, α = 150, площадь = 1,560 мм²
  - x = 95-130 мм: рециркуляция за водоблоком, α = 37, площадь = 5,460 мм²
  - x = 130-140 мм: повторное прилипание, α = 120, площадь = 1,560 мм²
  - x = 140-170 мм: рециркуляция за водоблоком 2, α = 37, площадь = 4,680 мм²
  α_back_средн = (2340×302 + 10920×92 + 1560×150 + 5460×37 + 1560×120 + 4680×37) / 26520 × 1.10 = 104.1 Вт/(м²·К)

**Коэффициент теплоотдачи: α_front = 128.6 Вт/(м²·К), α_back = 104.1 Вт/(м²·К)**

### 7.9. Механизм эффекта Коанда

Эффект Коанда обеспечивает прилипание высокоскоростной струи воздуха к вертикальной поверхности текстолита мезонина. Критерий прилипания:

```
Расстояние от щели до кромки мезонина: d = 5 мм
Высота щели: h = 3 мм
Критерий: d/h = 5/3 = 1.67 < 3.0 → прилипание гарантировано

Угол выхода 10.54° направлен к поверхности → усиливает прилипание
```

При прилипании струя распространяется вдоль поверхности мезонина на всю высоту обдува (120 мм), сохраняя высокую скорость и коэффициент теплоотдачи. Коэффициент усиления k_coanda = 1.15 учитывает дополнительное перемешивание пограничного слоя за счёт кривизны траектории струи при прилипании.

### 7.10. Распространение струи (jet spread)

Для турбулентной щелевой струи скорость убывает с расстоянием:
```
v(x)/v₀ = √(K / (x/h)),  K = 5.75,  v₀ = 17.1 м/с

При x = 20 мм:  v = 17.1 × √(5.75/6.67) = 17.1 × 0.929 = 15.9 м/с
При x = 50 мм:  v = 17.1 × √(5.75/16.67) = 17.1 × 0.587 = 10.0 м/с
При x = 100 мм: v = 17.1 × √(5.75/33.33) = 17.1 × 0.415 = 7.1 м/с
При x = 120 мм: v = 17.1 × √(5.75/40.0) = 17.1 × 0.379 = 6.5 м/с
При x = 150 мм: v = 17.1 × √(5.75/50.0) = 17.1 × 0.339 = 5.8 м/с
```

**При x = 120 мм скорость струи 6.5 м/с, что значительно превышает порог эффективного охлаждения (3 м/с).** Это подтверждает достаточность покрытия зоны 160×120 мм.

Расчёт для полной высоты мезонина 170 мм:
```
При x = 140 мм: v = 17.1 × √(5.75/46.67) = 5.8 м/с
При x = 160 мм: v = 17.1 × √(5.75/53.33) = 5.6 м/с
При x = 170 мм: v = 17.1 × √(5.75/56.67) = 5.5 м/с
```
Струя сохраняет скорость > 5.5 м/с на всей высоте мезонина 170 мм. Верхние 50 мм (Y = 120-170) содержат компоненты с низкой тепловой нагрузкой (~10-14 Вт), и естественная конвекция + «хвост» wall jet обеспечивают достаточное охлаждение этой зоны.

### 7.11. Ёмкость теплосъёма

```

  P_back = α_back × S_зоны × ΔT = 104.1 × 0.0192 × 45 = 90.1 Вт

Один мезонин (2 сопла):
  P_мезонин = 111.1 + 90.1 = 201.2 Вт

Оба мезонина (4 сопла):

```

# Спецификация сопла охлаждения мезонина V100

## 1. Назначение и количество

Каждый мезонин (2 шт) обдувается двумя соплами: лицевым (обдув текстолита с использованием эффекта Коанда) и тыльным (обдув корпуса водоблока и пластины-спредера VRM). Итого **4 сопла** на палубу. Все 4 сопла идентичны по геометрии, различается только ориентация при монтаже.

Сопло устанавливается на палубе в зазоре 40 мм между палубой и нижней кромкой мезонина. Конвергентный канал сужает поток от входной прорези 160×10 мм до выходной щели 156×3.0 мм. Выходная щель наклонена на 12° от горизонтали, направляя воздушный нож на нижнюю кромку вертикально установленного мезонина.

## 6. SlimSAS-кабели

### 6.1. Принцип

Сопла покрывают центральную зону мезонина (GPU + VRM). SlimSAS-разъёмы SFF-8654 расположены по краю мезонина. **Кабели НЕ проходят через тело сопла.** Каждый из 4 кабелей на мезонин проходит через отдельное окно палубы, расположенное за пределами зоны сопел.

### 6.2. Габариты разъёма SFF-8654

| Параметр | Значение |
| --- | ---: |
| Ширина корпуса разъёма | ~30 мм |
| Высота корпуса разъёма | ~10 мм |
| Длина разъёма (с фиксаторами) | ~38 мм |
| Диаметр кабеля у корня (первые 20 мм) | 4-5 мм |
| Минимальный радиус изгиба | 15-20 мм |

### 6.3. Окна палубы для SlimSAS

| Параметр | Значение |
| --- | --- |
| Количество окон | 4 (по одному на пару кабелей, 2 на мезонин) |
| Размер каждого окна | 32 × 15 мм |
| Расположение | Строго под разъёмами SFF-8654 на мезонине |
| Герметизация | Разрезная резиновая вставка с прижимной планкой |
| Радиус кромок окна | ≥ 2 мм |
| Зона | Вне проекции сопел, вне проекций PSU-отсеков |

### 6.4. Последовательность монтажа

1. Мезонины устанавливаются на боковые направляющие. SlimSAS-кабели подключаются к мезонину и свисают вниз.
2. Палуба с соплами опускается сверху. Сопла проходят мимо кабелей.
3. Кабели проходят через отдельные окна палубы для SlimSAS.
4. Окна герметизируются резиновыми вставками.
5. Сопла прикручиваются к палубе винтами M3 × 8 мм.

**Перед раскроем палубы необходимо физически проверить расположение разъёмов SFF-8654 на конкретных платах-носителях и разметить окна палубы по факту.**

### 7.3. Рабочая точка системы

Сопротивление сети:
```
ΔP = ξ × (ρ/2) × (Q/S_total)²
ΔP = 1.45 × 0.6 × (Q/0.01155)²
ΔP = 0.87 × (Q/0.01155)²
ΔP = 6521.6 × Q²
```

Уравнение рабочей точки:
```
23.63 × [1 − (Q/0.1652)²] = 6521.6 × Q²
23.63 = Q² × (6521.6 + 23.63/0.1652²)
23.63 = Q² × (6521.6 + 865.9)
23.63 = Q² × 7387.5
Q = √(23.63/7387.5) = 0.0566 м³/с
```

### 7.6. Скорость выхода из сопла мезонина

```

v_выхода = Q_одно_сопло / S_eff = 0.007835 / 0.000458 = 17.1 м/с

### 7.7. Число Рейнольдса

```
Dh = 2 × h = 2 × 3.0 = 6.0 мм (гидравлический диаметр узкой щели)
ν = 1.65 × 10⁻⁵ м²/с (кинематическая вязкость при 35 °C)

Re = v × Dh / ν = 17.1 × 0.006 / (1.65 × 10⁻⁵) = 6,222

Режим: турбулентный (Re > 4,000)
```

### 7.8. Коэффициент теплоотдачи (корреляции для щелевой струи)

**Важно:** Для расчёта теплоотдачи от щелевой струи (slot jet), импиджирующей на вертикальную поверхность, используются специализированные корреляции, а не формула Dittus-Boelter (применимая к течению в трубах).

#### 7.8.1. Зона импиджмента (stagnation zone, x = 0–15 мм)

Струя выходит из щели под углом 12° и попадает на нижнюю кромку мезонина. В зоне импиджмента коэффициент теплоотдачи максимален.

Корреляция для slot jet impingement:
```
Nu_stag = 0.62 × Re^0.5 × Pr^0.36 × (W/h)^0.15

Re = 6222,  Pr = 0.71,  W/h = 156/3 = 52

Re^0.5 = √6222 = 78.88
Pr^0.36 = 0.71^0.36 = 0.882
(W/h)^0.15 = 52^0.15 = 1.607

Nu_stag = 0.62 × 78.88 × 0.882 × 1.607 = 69.2

α_stag = Nu_stag × λ / Dh = 69.2 × 0.0262 / 0.006 = 302 Вт/(м²·К)
```

#### 7.8.2. Зона пристеночной струи (wall jet, x = 15–150 мм)

После импиджмента струя распространяется вдоль вертикальной поверхности мезонина. Коэффициент теплоотдачи убывает с расстоянием.

Корреляция для wall jet от щелевого сопла:
```
Nu_x = 0.05 × Re^0.67 × (x/h)^(-0.06)

Re^0.67 = 6222^0.67 = 495.0
Константа: 0.05 × 495.0 = 24.75

При x = 10 мм:  Nu = 24.75 × (10/3)^(-0.06) = 24.75 × 0.913 = 22.6
При x = 50 мм:  Nu = 24.75 × (50/3)^(-0.06) = 24.75 × 0.823 = 20.4
При x = 100 мм: Nu = 24.75 × (100/3)^(-0.06) = 24.75 × 0.767 = 19.0
При x = 150 мм: Nu = 24.75 × (150/3)^(-0.06) = 24.75 × 0.740 = 18.3
```

Среднее Nu_wall (интеграл от x=5 до x=150 мм):
```
∫(x/h)^(-0.06) dx от 5 до 150 = h × [(x/h)^0.94 / 0.94] от 5 до 150
= 0.003 × (50^0.94 − 1.667^0.94) / 0.94
= 0.003 × (40.31 − 1.613) / 0.94
= 0.003 × 41.167 = 0.1235

Среднее (x/h)^(-0.06) = 0.1235 / 0.145 = 0.852
Nu_wall_avg = 24.75 × 0.852 = 21.1

α_wall_avg = 21.1 × 0.0262 / 0.006 = 92.1 Вт/(м²·К)
```

#### 7.8.3. Средний коэффициент теплоотдачи

```
α_avg_base = (15 × 302 + 145 × 92.1) / 160
           = (4530 + 13355) / 160
           = 17885 / 160
           = 111.8 Вт/(м²·К)

Лицевая сторона (эффект Коанда, k = 1.15):
  α_front = 111.8 × 1.15 = 128.6 Вт/(м²·К)

Тыльная сторона (шероховатость водоблока, k = 1.10):
  α_back = 111.8 × 1.10 = 123.0 Вт/(м²·К)
```

**Коэффициент теплоотдачи: α_front = 128.6 Вт/(м²·К), α_back = 123.0 Вт/(м²·К)**

### 7.9. Механизм эффекта Коанда

Эффект Коанда обеспечивает прилипание высокоскоростной струи воздуха к вертикальной поверхности текстолита мезонина. Критерий прилипания:

```
Расстояние от щели до кромки мезонина: d = 3-5 мм
Высота щели: h = 3 мм
Критерий: d/h = 1.0–1.7 < 3.0 → прилипание гарантировано

Угол выхода 12° направлен к поверхности → усиливает прилипание
```

При прилипании струя распространяется вдоль поверхности мезонина на всю высоту обдува (120 мм), сохраняя высокую скорость и коэффициент теплоотдачи. Коэффициент усиления k_coanda = 1.15 учитывает дополнительное перемешивание пограничного слоя за счёт кривизны траектории струи при прилипании.

### 7.10. Распространение струи (jet spread)

Для турбулентной щелевой струи скорость убывает с расстоянием:
```
v(x)/v₀ = √(K / (x/h)),  K = 5.75,  v₀ = 17.1 м/с

При x = 20 мм:  v = 17.1 × √(5.75/6.67) = 17.1 × 0.929 = 15.9 м/с
При x = 50 мм:  v = 17.1 × √(5.75/16.67) = 17.1 × 0.587 = 10.0 м/с
При x = 100 мм: v = 17.1 × √(5.75/33.33) = 17.1 × 0.415 = 7.1 м/с
При x = 120 мм: v = 17.1 × √(5.75/40.0) = 17.1 × 0.379 = 6.5 м/с
При x = 150 мм: v = 17.1 × √(5.75/50.0) = 17.1 × 0.339 = 5.8 м/с
```

**При x = 120 мм скорость струи 6.5 м/с, что значительно превышает порог эффективного охлаждения (3 м/с).** Это подтверждает достаточность покрытия зоны 160×120 мм.

### 7.11. Ёмкость теплосъёма

Каждое сопло обдувает зону 160 × 120 мм = 0.0192 м². Зона 120 мм по высоте обоснована расчётом распространения струи (§7.10): при скорости выхода 17.1 м/с эффективное покрытие достигает 120-140 мм.

```
Лицевое сопло (текстолит):
  P_front = α_front × S_зоны × ΔT = 128.6 × 0.0192 × 45 = 111.1 Вт

Тыльное сопло (водоблок + VRM):
  P_back = α_back × S_зоны × ΔT = 123.0 × 0.0192 × 45 = 106.3 Вт

Один мезонин (2 сопла):
  P_мезонин = 111.1 + 106.3 = 217.4 Вт

Оба мезонина (4 сопла):
  P_итого_мез = 2 × 217.4 = 434.8 Вт
```

### 7.12. Проверка достаточности охлаждения

Водоблок Speedier XF-001-CO забирает ~95% тепла GPU и VRM в воду контура СЖО. Воздушный контур обслуживает оставшееся тепло: корпус водоблока, текстолит, зоны не покрытые водоблоком, разъёмы.

| Режим | Нагрузка на воздух (оценка, на мезонин) | Ёмкость охлаждения | Запас |
| --- | ---: | ---: | ---: |
| IDLE | ~80 Вт | 217.4 Вт | +137.4 Вт |
| Инференс (целевой) | ~100 Вт | 217.4 Вт | +117.4 Вт |
| Пик | ~120 Вт | 217.4 Вт | +97.4 Вт |

**Запас положительный во всех режимах. Минимальный запас при пике: +97.4 Вт (81%).**

### 7.14. Нагрев воздуха

```
